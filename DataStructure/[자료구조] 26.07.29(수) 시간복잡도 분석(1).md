## 1. 계산 복잡도와 점근적 복잡도

계산 복잡도(computational complexity)는 쉽게 말해서
알고리즘을 실행할 때 소비되는 자원의 양을 나타내는 개념이라고 할 수 있어.

이 자원의 양이란건 다양한 방식으로 측정될 수 있는데,
대표적으로

- 시간 복잡도(time complexity) : 알고리즘 실행시 알고리즘이 수행하는 연산의 횟수
- 공간 복잡도(space complexity) : 알고리즘 실행시 필요한 메모리 공간

이렇게 두 가지가 있어.

그리고 보통은 공간 복잡도보단 시간 복잡도가 더 주요하게 다뤄지지.

근데 이런 문제가 있어.
실행 시간은 결국 컴퓨터의 종류에 따라 달라지잖아?

구식 컴퓨터와 신식 컴퓨터로 동일한 알고리즘을 실행했을 때,
구식 컴퓨터가 신식 컴퓨터보다 20배 이상 많은 시간이 걸린다면,
시간 복잡도가 어떻게 된다고 해야할까?

그래서 실제로 시간 복잡도를 측정할 때는 현실의 시간 단위같은 것을 사용하지 않고,

예를 들어, $n$과 $t$ 사이에 선형 관계가 있다면,
$t = cn$이겠지?

처리할 파일이나 배열의 크기가 커질 수록 실행 시간도 그에 맞춰서 선형으로 커질테니까?
이런 식이야.

그리고 만약 이런 시간 복잡도를 나타내는 함수에서는,
보통 함수의 크기를 실질적으로 변화시키지 않는 항들은 제거해서 표현해.

예를 들어,

$t = n^2 + n + \log n + 100$

이렇다고 할 때,
결국 최종적으로 실행시간 $t$에 영향을 가장 많이 끼치는건 $n^2$라는 항이니까,
딱 이것만 남기고 제거하는 식으로.

$t = n^2$

물론 이게 근사치긴 한데,
알고리즘의 시간복잡도를 나타내기 위한 표현으로는 충분히 좋아.

특히 $n$의 값이 클 경우, 즉 점근적으로 볼 경우 더 확실히 원래 함수와 비슷해지겠지.

어쨌든 이렇게 가장 영향을 많이 끼치는 항을 제외한 항을 제거하고 시간 복잡도를 측정한 것을
점근적 복잡도(asymototic complexity)라고 해.

## 2. 빅오 표기법

앞에서 설명한 점근적 복잡도를 나타내기 위한 제일 대표적인 표현으로
빅오 표기법(Big-O Notation)이 있어.

쉽게 설명하자면,
앞서 설명한 점근적 복잡도를 $O(g(n))$으로 표기한 표기법인데,

- $O(1)$ : 상수 시간 복잡도, 데이터 수에 상관없이 걸리는 시간이 일정함, 예시 : $t = k$
- $O(n)$ : 선형 시간 복잡도, 데이터 수에 맞춰 걸리는 시간이 일정하게 늘어남, 예시 : $t = n + k$
- $O(n^2)$ : 제곱 시간 복잡도, 데이터 수에 맞춰 걸리는 시간이 제곱으로 늘어남, 예시 : $t = n^2 + n + k$

이런식으로 표현해.

말 그대로 앞서 설명한 점근적 복잡도를 표현하는 표기법이라고 할 수 있지.

더 정확히 말하자면,
빅오 표기법은 단순히 함수에서 가장 큰 항만 남겨 적는 표기법은 아니고,

알고리즘의 실행 시간이 특정 함수보다 점근적으로 빠르게 증가하지 않는다는 것을 나타내는 표기법이야.

빅오 표기법의 정의 자체는

> $f(n) = O(g(n))$이란,
> $g(n)$을 고정된 상수배만큼 키웠을 경우에 
> 어느 시점 이후부터 $f(n)$보다 항상 크다는 뜻이다.

라는건데..
솔직히 이게 무슨 소리인지 모르겠지?

좀 쉽게 설명해보자면,

$f(n)$이 실제 연산 횟수를 나타내는 함수고,
$g(n)$은 증가율을 비교하기 위한 기준이 되는 함수, 즉 빅오 표기법에 들어가는 함수일 때,

$g(n)$에 어떤 고정된 상수 $c$를 곱했을 때
어떤 $N$이후의 모든 $n$에서 $f(n) \leq c \times g(n)$이 성립하면
$f(n) = O(g(n))$이라고 한다는거야.

솔직히 이래도 어렵긴 한데,
하.. 이걸 어떻게 쉽게 설명해야할까..

그냥 예시를 들어볼게.. 

$f(n) = 3n + 2$라고 하자.
그리고 빅오 표기법으로 표기했을 때 $O(n)$이 되는지 한번 보자고.

$f(n) = O(n)$이 되어야하니까,
어떤 $n$부터는 계속 $3n + 2 \leq cn$이 되어야 해.
$c = 4$로 두고, 그리고 $n \geq 2$인 경우에는 항상 $3n + 2 \leq 4n$이 성립하겠지?
그러므로 $f(n) = O(n)$가 된다는거야.

근데 결국 시간 복잡도가 이렇다는건,
$f(n)$이 $g(n)$보다 점근적으로 빠르게 증가하지 않는다는거잖아?

딱 이런 느낌이지..

> $O(g(n))$이란,
> 결국 점근적으로 봤을 때는, 즉 $n$을 충분히 크게 봤을 때는
> $c \times g(n)$보다 $f(n)$이 작거나 같다는 뜻이다.
> 즉 $n$을 충분히 크게 봤을 때는 $c \times g(n)$보다 $f(n)$이 커지지 않는다는 뜻이다.

라는 느낌으로 빅오 표기법을 쓴다는거지..

### 짧은 요약

어쨌든, 빅오 표기법이란

수학적으로 봤을 때는

> $O(g(n))$의 형태로
> 점근적으로, $n$을 충분히 크게 봤을 때
> $f(n) \leq c \times g(n)$이 되는 것을 표현하는 표기법

이라고 할 수 있고,

좀 더 간추려 말했을 때는

> $O(g(n))$의 형태로
> 점근적으로, $n$을 충분히 크게 봤을 때
> $c \times g(n)$이 $f(n)$의 상한이 된다는 것을 기반으로 
> 시간복잡도를 표현하는 표기법

이러고 할 수 있겠네.

그냥 제일 빅오를 빠르게 구하는 방법만 놓고 보자면

> 가장 높은 차수의 항만 남기고 그항의 상수 계수는 생략해서 표현한다.

라고 할 수 있고,
수학적 원리가 앞서 길게 설명했던 그거라고 보면 돼.

솔직히 나도 머리아파 뒤질뻔함..

그냥 빅오의 엄밀한 정의는 더럽게 복잡하니까, 적당히 이 정도로 이해해도 될 것 같아..
