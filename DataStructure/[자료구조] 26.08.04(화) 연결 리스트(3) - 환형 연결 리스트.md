## 0. 서론

이번에는 연결 리스트 기본의 마지막,
환형 연결 리스트(Circular Linked List)야.

이것까지 하면, 
기본적인 연결리스트의 형태는 다 배웠다고 할 수 있겠지.

이번 글에서는,

- 환형 연결 리스트의 장점
- 환형 연결 리스트의 기본 구조
- 환형 연결 리스트의 구현
  - 순회
  - 맨 앞 삽입 / 맨 뒤 삽입
  - 맨 앞 삭제 / 맨 뒤 삭제
- 요약 정리

이 정도를 다룰거야.

아 그리고 `prev` 포인터는 없다?
`next` 포인터만을 가진
단일 환형 연결 리스트야.

물론 `tail` 포인터는 사용할게.

## 1. 환형 연결 리스트의 장점

기존 연결 리스트들의 단점이 뭐였을까?

바로

> 시작 노드와 끝 노드가 이어져있지 않아서 
> 시작 노드와 끝 노드 사이를 자연스럽게 이동할 수 없다.

라고 할 수 있어.

단일이든 이중이든 기존 연결 리스트는
시작 노드와 끝 노드가 `nullptr`로 완전히 분리되어있어서
`next` / `prev`만 따라가면 시작 노드와 끝 노드 사이를 자연스럽게 넘어갈 수 없었다는거야.

환형 연결 리스트는
이런 문제를
시작 노드와 끝 노드가 서로를 가리키도록 해서
시작 노드와 끝 노드 사이를 자연스럽게 넘어갈 수 있게 했어.

이게 바로 환형 연결 리스트의 장점이야.

> 시작 노드와 끝 노드가 이어져있어서
> 시작 노드와 끝 노드 사이를 자연스럽게 이동할 수 있다.

## 2. 환형 연결 리스트의 기본 구조

> 이 글에서는, 단일 환형 연결 리스트만 다뤄.
> 이중 환형 연결 리스트는 너무 복잡해져서 다루지 않아.

환형 연결 리스트는,
기존의 연결 리스트와 다른 점이 하나밖에 없어.

```text
기존 연결 리스트

[ head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ] 
                                                                ^
                                                                |
                                                                |
                                                             [ tail ]
```

```text
환형 연결 리스트
                  ┌------------------------------------------------------┐
                  |                                                      |
                  ↓                                                      |
[ head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ]
                                                                ^
                                                                |
                                                             [ tail ]


```

이렇게, 마지막 노드의 `next` 포인터가 첫 노드, 즉 `head`와 같은 주소를 가리킨다는거.

노드 구조도 똑같고,
클래스 구조도 사실상 거의 똑같지만,

- 순회
- 맨 앞 / 맨 뒤 삽입
- 맨 앞 / 맨 뒤 삭제

이런 것들은 달라.

일단 노드 구조는 기존 연결 리스트와 동일하게,

```cpp
class Node {
public:
    int data;
    Node* next;
    
    Node(int element) {
        data = element;
        next = nullptr;
    }
};
```

이렇게 돼.

클래스 구조도

```cpp
class CSLList{
private:
    Node* head;
    Node* tail;
public:
    CSLList(){
        head = nullptr; 
        tail = nullptr;
    }
    ~CSLList();
    
    Node* find(int target);
    
    void insert_front(int element);
    bool insert_node(int target, int element);
    void insert_end(int element);
    
    bool delete_front();
    bool delete_node(int target);
    bool delete_end();
};
```

기존 단일 링크드 리스트랑 비슷하고.

그리고, 보통 환형 연결 리스트에서는 `head`나 `tail` 중 하나만 사용하는 경우가 많아.

보통은 `tail`만 쓰는데, `tail->next`가 사실상 `head`이기 때문에 그래.
물론 포인터 연산 순서는 신경 써야하겠지?
`tail->next`를 먼저 덮어쓰면 `head`를 찾을 수 없을테니까.
그리고 단일 연결 리스트인 경우에는 거꾸로 돌아가기가 어렵기도 해서 `tail`을 주로 쓰지.
`head->prev`가 `tail`인데 
단일 환형 링크드 리스트에는 `prev` 포인터가 없으니까.

> 나는 초반에는 둘 다 사용하는데,
> 후반에는 도저히 못하겠어서 `tail`위주의 설명을 해..

## 3. 환형 연결 리스트의 구현

### 3-1. 순회

순회가 의외로 기존 연결 리스트와 차이가 있어.
기존에는, `current` 노드가 `nullptr`라면 해당 리스트의 끝으로 감지해서 종료했잖아?

근데 환형 연결 리스트에는 마지막 노드의 `next` 포인터가 `nullptr`가 아닌 첫 노드를 가리키기 때문에
무작정 `current != nullptr`로 반복 조건을 잡아놓으면 무한으로 순회하는 문제가 생길 수 있어.

그래서,
`current != head`로 반복 조건을 잡아놓고,
`current == head`로 실행되는 첫 노드에 대한 순회는 무조건 실행되도록
do-while문을 사용해서 구현해야해.

```cpp
Node* CSLList::find(int target){
    if (head == nullptr) return nullptr;
    
    Node* current = head;
    
    do { // 순회의 첫 시작 노드인 head는 current != head에 걸리지 않기 위해서 이렇게 함
        
        if (current->data == target) {
            return current;
        }
        
        current = current->next;
        
    } while (current != head);
    
    return nullptr;
}
```

### 3-2. 삽입

중간 삽입은 기존 연결 리스트랑 같아서 패스하고,
환형 구조때문에 달라지는 맨 앞 삽입 / 맨 뒤 삽입을 보자.

### 3-2-1. 맨 앞 삽입

일단 맨 앞 삽입부터 보자면,

결국 기존 연결 리스트와 달라지는 점이 `tail` 포인터가 가리키는 노드, 
즉 마지막 노드의 `next` 포인터를
맨앞에 새로 삽입한 노드로 이어줘야한다는 점이야.

그래서,

1. 새 노드 생성
2. 새 노드의 `next` 포인터를 `head`로 변경
3. `head`가 새 노드를 가리키도록 변경
4. 마지막 노드의 `next` 포인터가 새 노드를 가리키도록 변경

이렇게 해야해.

1. 
```text
                  ┌------------------------------------------------------┐
                  |                                                      |
                  ↓                                                      |
[ head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ]
                                                                ^
                                                                |
        [ data 0 | next ]                                    [ tail ]
```
2.
```text
                  ┌------------------------------------------------- ----┐
                  |                                                      |
                  ↓                                                      |
[ head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ]
                  ^                                             ^
                  |                                             |
      [ data 0 | next ]                                      [ tail ]
```
3.
```text
                  ┌------------------------------------------------------┐
                  |                                                      |
                  ↓                                                      |
[ head ]      [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ]
    |             ^                                             ^
    ↓             |                                             |
      [ data 0 | next ]                                      [ tail ]
```
4.
```text
          ┌--------------------------------------------------------------┐
          |                                                              |
          |                                                              |
[ head ]  |   [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ]
    |     |       ^                                             ^
    ↓     ↓       |                                             |
      [ data 0 | next ]                                      [ tail ]
```

```cpp
void CSLList::insert_front(int element){
    
    Node* new_node = new Node(element); // 1
    
    if (head == nullptr) { // 빈 리스트일 때 처리
        head = new_node;
        tail = new_node;
        new_node->next = new_node; // 노드가 하나밖에 없으므로 자기 자신을 가리킴
        
        return;
    }
    
    new_node->next = head; // 2
    head = new_node; // 3
    tail->next = new_node; // 4
}
```

`tail` 포인터 기반 맨 앞 노드 변경도 보자면,

1. 새 노드 생성
2. 새 노드의 `next` 포인터를 `tail->next`로 변경
3. `tail` 노드의 `next` 포인터를 새 노드를 가리키도록 변경

이렇게 할 수 있어.

```cpp
void CSLList::insert_front(int element) {

    Node* new_node = new Node(element); // 1
    
    if (tail == nullptr){ // 빈 리스트일 때 처리
        head = new_node;
        tail = new_node;
        new_node->next = new_node;
        
        return;
    }
    
    new_node->next = tail->next; // 2
    tail->next = new_node; // 3
    head = new_node;
}
```

### 3-2-2. 맨 뒤 삽입

이제 맨 뒤 삽입도 보자면,

결국 기존 연결 리스트와 다른 점이
새로 생성한 노드의 `next` 포인터를 `head`(`tail->next`)와 이어줘야한다는 점이야.

1. 새 노드 생성
2. 새 노드의 `next` 포인터가 `head`(`tail->next`)를 가리키도록 변경
3. `tail` 노드의 `next` 포인터가 새 노드를 가리키도록 변경
4. `tail`이 새 노드를 가리키도록 변경

이렇게 하면 돼.

1.
```text
                  ┌------------------------------------------------------┐
                  |                                                      |
                  ↓                                                      |
[ head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ]
                                                                ^
                                                                |
        [ data 4 | next ]                                    [ tail ]
```
2.
```text
                  ┌------------------------------------------------------┐
                  |                                                      |
                  ↓                                                      |
[ head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ] <--- [ tail ]
                  ^                                              
                  |                                             
                  |                                         [ data 4 | next ]
                  |                                                      |
                  |                                                      |
                  └------------------------------------------------------┘
```
3.
```text
[ head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ] <--- [ tail ]
                  ^                                                   |
                  |                                                   ↓
                  |                                         [ data 4 | next ]
                  |                                                      |
                  |                                                      |
                  └------------------------------------------------------┘
```
4.
```text
[ head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ] 
                  ^                                                   |
                  |                                                   ↓
                  |                                         [ data 4 | next ] <--- [ tail ]
                  |                                                      |
                  |                                                      |
                  └------------------------------------------------------┘
```

```cpp
void CSLList::insert_end(int element){
    Node* new_node = new Node(element); // 1
    
    if (tail == nullptr) {
        head = new_node;
        tail = new_node;
        new_node->next = new_node;
        
        return;
    }
    
    // 2번과 3번을 반대로 하면 이미 갱신된 tail->next를 new_node->next가 사용하게 됨
    // 즉, new_node가 자기 자신을 가리키게 되고, head에 접근할 방법도 tail만 쓰는 구조에서는 없어짐
    new_node->next = tail->next; // 2
    tail->next = new_node; // 3
    tail = new_node; // 4
}
```

그럼 `head`를 사용하는 맨 뒤 삽입도 보자.

근데 이건 `tail` 없이 하려면 순회 없이는 불가능해.
`head`부터 맨 뒤 노드까지 간 후,
그 노드에서 작업을 수행해야하다보니까..

1. 새 노드 생성
2. 순회하며 마지막 노드를 획득
3. 새 노드의 `next` 포인터를 `head`(마지막 노드의 `next` 포인터)로 변경
4. 마지막 노드의 `next` 포인터를 새 노드를 가리키도록 변경

이렇게 하면 돼.

1.
```text
                  ┌------------------------------------------------------┐
                  |                                                      |
                  ↓                                                      |
[ head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ]
                                                                

                                                            [ data 4 | next ]
```
2.
```text
                  ┌------------------------------------------------------┐
                  |                                                      |
                  ↓                                                      |
[ head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ]
                                                                ^
                                                                |
                                                                |
                                                             마지막 노드  
                                                             
                                                             
                                                            [ data 4 | next ]
```
3.
```text
                  ┌------------------------------------------------------┐
                  |                                                      |
                  ↓                                                      |
[ head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ]
                  ^                                             ^
                  |                                             |
                  |                                             |
                  |                                          마지막 노드
                  | 
                  |                                         [ data 4 | next ]
                  |                                                      |
                  └------------------------------------------------------┘
```
4.
```text
[ head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ]
                  ^                                                   |
                  |                                                   |
                  |                                                   |
                  |                                                   |
                  |                                                   ↓
                  |                                         [ data 4 | next ]
                  |                                                      |
                  └------------------------------------------------------┘
```

```cpp
void CSLList::insert_end(int element) {
    Node* new_node = new Node(element); // 1
    
    if (head == nullptr) { // 빈 리스트인 경우
        head = new_node;
        tail = new_node;
        new_node->next = new_node;
        return;
    }
    
    Node* current = head;
    while (current->next != head){ // 2
          current = current->next;
    }
    
    new_node->next = head; // 3
    current->next = new_node; // 4
}
```

### 3-3. 삭제

이것도 중간 삭제는 기존 연결 리스트랑 똑같아서,
맨 앞 삭제 / 맨 뒤 삭제만 보자.

그리고, 여기서부터는 `tail` 기반만 설명할게.
`head`와 `tail` 기반 삭제를 설명하려 했던 과거의 나 자신이 저주스럽다..
분량 2배 폭발..

기존의 `CSLList` 클래스의 `head` 멤버도 없다고 생각해줘 여기부터는..

```cpp
class CSLList {
private:
    Node* tail;
    // 이제부턴 head 포인터 없음!
public:
    // ...
};
```

그래서 `tail` 기반의 삭제만 설명할게.

이 뒤의 삭제 연산은 앞에서 사용한 `head + tail`을 사용하는 구현과는 별개야.
오직 `tail`만 사용함.

### 3-3-1. 맨 앞 삭제

`tail->next`가 첫 노드니까, 삭제할 노드는 `tail`만 있어도 바로 얻을 수 있어.
(물론 이전의 삽입에서도 그렇고..)

이것도 기존 연결 리스트와의 다른 점이 맨 뒤의 노드의 `next` 포인터를 
맨 앞의 노드와 다시 이어줘야한다는 점이야.

1. 맨 앞의 노드를 저장
2. `tail` 노드의 `next` 포인터를 맨 앞의 노드의 `next` 포인터로 변경
3. 저장한 맨 앞 노드 삭제

이렇게 하면 돼.

1.
```text
    ┌------------------------------------------------------┐
    |                                                      |
    ↓                                                      |
[ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ]
    ^                                             ^
    |                                             |
 target                                        [ tail ]
```
2.
```text
                           ┌-------------------------------┐
                           |                               |
                           ↓                               |
[ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ]
    ^                                             ^
    |                                             |
 target                                        [ tail ]
```

3.
```text
                   ┌-------------------------------┐
                   |                               |
                   ↓                               |
[ 삭제됨 ]      [ data 2 | next ] ---> [ data 3 | next ]
    ^                                             ^
    |                                             |
 target                                        [ tail ]
```

```cpp
bool CSLList::delete_front() {
    if (tail == nullptr) { // 빈 리스트인 경우
        return false;
    }
    
    Node* target = tail->next; // 1
    
    if (target == tail) { // 노드가 하나뿐인 경우
        tail = nullptr;
        delete target;
        
        return true;
    }
    
    tail->next = target->next;
    
    delete target;
    
    return true;
}
```

### 3-3-2. 맨 뒤 삭제

여기도 `head`만 사용한 맨 뒤 삽입처럼,
순회를 해서 맨 뒤 노드의 이전 노드를 알아내야해.

그래서,

1. 기존 `tail` 노드(맨 뒤 노드)를 저장
2. 첫 노드부터 순회하며 `tail` 노드의 이전 노드(`next == tail`)를 획득
3. 이전 노드의 `next` 포인터를 첫 노드(`tail->next`)와 연결
4. 이전 노드를 새로운 `tail`로 변경
5. 저장해두었던 기존 `tail` 노드 삭제

이렇게 진행돼.

1.
```text
    ┌------------------------------------------------------┐
    |                                                      |
    ↓                                                      |
[ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ] <--- [ tail ]
                                                  ^
                                                  |
                                                target
```
2.
```text
    ┌------------------------------------------------------┐
    |                                                      |
    ↓                                                      |
[ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ] <--- [ tail ]
                           ^                      ^
                           |                      |
                        previous                target
```
3.
```text
    ┌-------------------------------┬----------------------┐
    |                               |                      |
    ↓                               |                      |
[ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | next ] <--- [ tail ]
                           ^                      ^
                           |                      |
                        previous                target
```
4.
```text
    ┌-------------------------------┬----------------------┐
    |                               |                      |
    ↓                               |                      |
[ data 1 | next ] ---> [ data 2 | next ]      [ data 3 | next ]
                           ^                      ^
                           |                      |
                        [ tail ]                target
```
5.
```text
    ┌-------------------------------┐
    |                               |                      
    ↓                               |                      
[ data 1 | next ] ---> [ data 2 | next ]      [ 삭제됨 ]
                           ^                      ^
                           |                      |
                        [ tail ]                target
```

```cpp
bool CSLList::delete_end() {
    if (tail == nullptr) { // 빈 리스트일 경우
        return false;
    }
    
    if (previous == tail) { // 노드가 하나뿐일 경우
        tail = nullptr;
        delete target;
        
        return true;
    }
    
    Node* target = tail; // 1
    
    Node* previous = tail->next;
    while (previous->next != tail) { // 2
        previous = previous->next;
    }
   
    
    previous->next = tail->next; // 3
    tail = previous; // 4
    
    delete target; // 5
    
    return true;
}
```

### 3-4. 대략적인 시간복잡도

- 인덱스 접근 : 최악의 경우 마지막 노드까지 순회해야하므로 $O(n)$
- 순차 탐색 : 최악의 경우 모든 노드를 전부 순회해야하므로 $O(n)$
- 맨 앞 삽입 / 맨 뒤 삽입 : 고정된 횟수의 포인터 연산만 수행하므로 $O(1)$
- 맨 앞 삭제 : 고정된 횟수의 포인터 연산만 수행하므로 $O(1)$
- 맨 뒤 삭제 : `tail`만 사용하는 경우 맨 앞부터 맨 뒤 노드까지 순회해야하므로 $O(n)$
- 중간 삽입 : 최악의 경우 모든 노드를 다 돌아야하므로 $O(n)$, 위치를 알고있는 경우 $O(1)$
- 중간 삭제 : 최악의 경우 모든 노드를 다 돌아야하므로 $O(n)$, 위치를 알고있는 경우 $O(1)$

## 4. 기존 연결 리스트와의 차이

앞에서도 설명했지만,
첫 노드와 마지막 노드가 서로 이어져있다는 점이 가장 큰 차이야.

결국 첫 노드와 마지막 노드가 연결되어있기 때문에
리스트의 끝에 도달한 뒤 다시 처음으로 이동하는 연산이 매우 자연스럽고 빨라서,
큐(Queue)같은걸 연결 리스트로 구현할 때 사용하기 좋아.

그리고 `tail` 포인터 하나로만으로도 첫 번째 노드와 마지막 노드에 $O(1)$으로 접근할 수 있어.
처음과 끝에 많이 접근하는 경우 좋지.

## 5. 요약 정리

1. 단일 환형 연결 리스트는 끝 노드가 다음 노드로 반대편을 가리켜,
특정 노드에서 모든 노드로 이동할 수 있는 선형 자료구조이다.
2. 이중 환형 연결 리스트는 양 끝의 노드가 서로를 가리켜,
특정 노드에서 모든 노드로 이동할 수 있는 선형 자료구조이다.
3. 순회할 때는 무한한 순회가 발생하지 않도록 `current == head`일 때 까지만 반복해야한다.
4. 삽입할 때는 기존 연결 리스트와 크게 다르지 않지만,
맨 앞 / 맨 뒤에 삽입하는 경우에는 
(단일 연결 리스트의 경우) 맨 뒤의 포인터를 맨 앞으로 이어줘야한다.
5. 삭제할 때도 기존 연결 리스트와 크게 다르지 않지만,
맨 앞 / 맨 뒤의 노드를 삭제하는 경우에는
(단일 연결 리스트의 경우) 맨 뒤의 포인터를 맨 앞으로 이어줘야한다.
6. 이 글에는 안 썼지만 동적으로 생성한 모든 노드는 소멸자에서 순차적으로 해제해주어야한다.
7. 복사할 때는 깊은 복사를 수행하도록
별도의 복사 생성자 / 복사 대입 연산자를 구현해주어야 한다.
