## 0. 서론

저번에는 다음 노드를 가리키는 `next` 포인터만을 가진
단일 연결 리스트를 공부했었고,

단일 연결 리스트의

- 순회
- 삽입
- 삭제

까지 알아봤었지.

이번에는 이전 노드를 가리키는 `prev` 포인터까지 가진
이중 연결 리스트를 공부할거야.

- 단일 연결 리스트의 한계
- 이중 연결 리스트의 기본 구조
- 이중 연결 리스트의 구현
  - 순회
  - 삽입
  - 삭제
  - 소멸자
  - 시간복잡도
- 단일 연결 리스트와의 비교
- 요약 정리

이 순으로.

그리고 단일 연결 리스트 글에서느다루지 못했던

- `tail` 포인터
- 복사 생성자 / 복사 대입 연산자

까지 할 생각이야.

## 1. 단일 연결 리스트의 한계와 이중 연결 리스트

단일 연결 리스트는, 삭제 연산을 해야할 때 포인터 두 개를 이동시켜야 했었어.

1. 
```text
삭제할 노드 = 2번 노드(data 2)

[ Head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]
                   ^                    ^
                   |                    |
                previous             current
```
2. 
```text
                           ┌-----------------------------------┐
                           |                                   ↓
[ Head ] ---> [ data 1 | next ]      [ data 2 | next ] ---> [ data 3 | nullptr ]
                   ^                    ^
                   |                    |
                previous             current      
```
3.
```text
                           ┌-----------------------------------┐
                           |                                   ↓
[ Head ] ---> [ data 1 | next ]                             [ data 3 | nullptr ]
                   ^                    ^
                   |                    |
                previous             current(삭제됨)    
```

이렇게 말이야.

근데 이게 결국 이전 노드의 `next` 포인터를
삭제한 노드의 다음 노드로 이어주기 위해서 이전 노드의 포인터를 같이 들고있어야 한단말이야?

이중 연결 리스트는 이 점에서 단일 연결 리스트의 한계를 극복해줘.

한 노드 안에서

- `data`
- 이전 노드를 가리키는 포인터(`prev` 포인터)
- 다음 노드를 가리키는 포인터(`next` 포인터)

이렇게 세 가지의 멤버를 가지고,
노드 삭제 말고도 **이전 노드의 정보가 필요한 경우**에
빠르게 이전 노드의 정보를 얻을 수 있어.

## 2. 이중 연결 리스트의 기본 구조

이중 연결 리스트와 연결 리스트가 근본적으로 다른점은,
딱 노드에 이전 노드를 가리키는 포인터가 있다는 점이야.

이 점 때문에,
연결 리스트에 대한 연산도 달라지지.

각 노드는 대략 이렇게,

```cpp
class Node {
public:
    int data;
    Node* prev; // 이거 추가됨
    Node* next;
};
```

- 해당 노드의 저장되어있는 데이터를 나타내는 `data`
- 이전 노드를 가리키는 `prev` 포인터
- 다음 노드를 가리키는 `next` 포인터

이렇게 구성돼.

이 노드 여러개를 `head` 포인터와 함께 연결하면,

```text
               +-------------------------+  --->  +----------------------+ ---> 
[ head ] --->  | nullptr | data 1 | next |        | prev | data 2 | next |      ...
               +-------------------------+  <---  +----------------------+ <---
```

이렇게 하나의 리스트가 만들어져.

각 노드는 `prev` 포인터로 이전 노드를 가리키고,
`next` 포인터로 다음 노드를 가리켜.

첫 노드는 이전 노드가 없기 때문에 `prev` 포인터가 `nullptr`이고,
마지막 노드는 다음 노드가 없기 때문에 `next` 포인터가 `nullptr`이야.

그리고 전에 단일 연결 리스트 설명할 때 안 다뤘던 부분인데,
별도로 노드의 끝을 나타내는 `tail` 포인터가 있어.

```text
                  <--- +-----------------------+
[ head ] ---> ...      | prev | data | nullptr | <--- [ tail ]
                  <--- +-----------------------+
```

이건 단일 연결 리스트에선 의도적으로 생략했지만,
이중 연결 리스트에서는 역방향 순회를 가능하게 해주는 중요한 포인터라 포함시켰어.

그리고 삽입 연산같은 경우,

```text
               +-------------------------+  -×->  +----------------------+ ---> 
[ head ] --->  | nullptr | data 1 | next |        | prev | data 2 | next |      ...
               +-------------------------+  <-×-  +----------------------+ <---
                            ^         ↓              ↓       ^
                            |    +----------------------+    |
                            └----| prev | data 1 | next |----┘
                                 +----------------------+

```

이렇게 

1. 삽입할 노드의 `next` 포인터를 삽입할 위치의 다음 노드와 이어주고,
2. 삽입할 노드의 `prev` 포인터를 삽입할 위치의 전 노드와 이어주고,
3. 삽입할 위치의 전 노드의 `next` 포인터를 삽입할 노드와 이어주고,
4. 삽입할 위치의 다음 노드의 `prev` 포인터를 삽입할 노드와 이어주면 돼.


삭제 연산같은 경우,

```text
               +-------------------------+  --->  +----------------------+ ---> 
[ head ] --->  | nullptr | data 1 | next |        | prev | data 2 | next |      ...
               +-------------------------+  <---  +----------------------+ <---
                            ^         ×              ×       ^
                            ×    +----------------------+    ×
                            └----| prev | data 1 | next |----┘
                                 +----------------------+

```

이렇게

1. 삭제할 위치의 전 노드의 `next` 포인터를 삭제할 노드의 다음 노드로 이어주고
2. 삭제할 위치의 다음 노드의 `prev` 포인터를 삭제할 노드의 전 노드로 이어주고
3. 삭제할 노드를 삭제하면 돼.

노드와 클래스의 기본 구조는,

```cpp
class Node {
public:
    int data;
    Node* prev;
    Node* next;
    
    Node(){
        data = 0;
        prev = nullptr;
        next = nullptr;
    }
    Node(int element) {
        data = element;
        prev = nullptr;
        next = nullptr;
    }
};
```

```cpp
class DLList {
private:
    Node* head;
    Node* tail;
public:
    DLList(){
        head = nullptr;
        tail = nullptr;
    }

    DLList(const DLList&);
    DLList& operator=(const DLList&);

    ~DLList();
    void clear();
    
    Node* find(int target);
    Node* find_reverse(int target);
    
    void insert_front(int element);
    bool insert_node(int target, int element);
    void insert_end(int element);
    
    bool delete_front();
    bool delete_node(int target);
    bool delete_end();
};
```

대략 이 정도로 구현할 수 있어.

## 3. 이중 연결 리스트의 구현

### 3-1. 노드 순회 및 탐색

탐색은 단일 연결 리스트와 비슷해.

하지만 `tail` 포인터와 `prev` 포인터를 이용한 역방향 순회가 가능하다는 점이 차이점이지.

1. 현재 노드를 본다.
2. `data`가 찾는 값인지 확인한다.
3. 찾는 값이면 해당 노드를 반환하고 아니라면 다음 노드로 넘어간다.

```cpp
// 정방향 순회
Node* DLList::find(int target) {
    Node* current = head; // head부터 시작
    
    while (current != nullptr) {
        if (current->data == target) {
            return current;
        }
        
        current = current->next; // 계속 next로 순회
    }
    
    return nullptr;
}

// 역방향 순회
Node* DLList::find_reverse(int target) {
    Node* current = tail; // tail부터 시작
    
    while (current != nullptr) {
        if (current->data == target) {
            return current;
        }
        
        current = current->prev; // 계속 prev로 순회
    }
    
    return nullptr;
}
```

### 3-2. 새로운 노드 삽입

단일 연결 리스트와 다르게,
세 가지 경우로 볼 수 있어.

1. 맨 앞에 새로운 노드 삽입
2. 맨 뒤에 새로운 노드 삽입(사실상 `tail` 포인터를 이용하는 맨 앞 삽입)
3. 중간에 새로운 노드 삽입

일단 첫 번째부터 보자.

맨 앞에 새로운 노드를 삽입하는 경우는,

1. 새 노드 생성
2. 새 노드의 `next`를 `head`로 변경
3. `next` 노드의 `prev` 포인터를 새 노드로 변경
4. `head`가 새 노드를 가리키도록 변경

이렇게 진행돼.

1.

```text
               +-------------------------+  --->  +----------------------+
[ head ] --->  | nullptr | data 1 | next |        | prev | data 2 | next |  ...
               +-------------------------+  <---  +----------------------+


               +----------------------------+
               | nullptr | data 0 | nullptr |
               +----------------------------+
```

2.

```text
               +-------------------------+  --->  +----------------------+
[ head ] --->  | nullptr | data 1 | next |        | prev | data 2 | next |  ...
               +-------------------------+  <---  +----------------------+
                         ^
                         |
               +-------------------------+
               | nullptr | data 0 | next |
               +-------------------------+
```

3.

```text
               +----------------------+  --->  +----------------------+
[ head ] --->  | prev | data 1 | next |        | prev | data 2 | next |  ...
               +----------------------+  <---  +----------------------+
                    |          ^
                    |          |
                    ↓          |
               +-------------------------+
               | nullptr | data 0 | next |
               +-------------------------+
```

4.

```text
               +----------------------+  --->  +----------------------+
               | prev | data 1 | next |        | prev | data 2 | next |  ...
               +----------------------+  <---  +----------------------+
                    |          ^
                    |          |
                    ↓          |
               +-------------------------+
[ head ] --->  | nullptr | data 0 | next |
               +-------------------------+
```

```cpp
void DLList::insert_front(int element){
    Node* new_node = new Node(element); // 1
    
    if (head == nullptr) { // 빈 리스트인 경우 예외처리
        head = new_node;
        tail = new_node;
        return;
    }
    
    new_node->next = head; // 2
    new_node->next->prev = new_node; // 3
    head = new_node; // 4
}
```

두 번째로, 맨 뒤에 새로운 노드를 삽입하는 경우는,

1. 새 노드 생성
2. 새 노드의 `prev` 포인터를 `tail`로 변경
3. `prev` 노드의 `next` 포인터를 새 노드로 변경
4. `tail` 포인터를 새 노드로 변경

```cpp
void DLList::insert_end(int element) {
    Node* new_node = new Node(element); // 1
    
    if (head == nullptr) { // 빈 리스트인 경우 예외처리
        head = new_node;
        tail = new_node;
        return;
    }
    
    new_node->prev = tail; // 2
    new_node->prev->next = new_node; // 3
    tail = new_node; // 4
}
```

세 번째로, 특정 노드 뒤에 새로운 노드를 삽입하는 경우는,

1. 삽입할 지점 찾기
2. 새 노드 생성
3. 새 노드의 `next`를 `prev` 노드의 `next`로 변경
4. 새 노드의 `prev`를 `next` 노드의 `prev`(`prev` 노드)로 변경
5. `prev` 노드의 `next`를 새 노드로 변경
6. `next` 노드의 `prev`을 새 노드로 변경

```cpp
bool DLList::insert_node(int target, int element) {
    Node* prev_node = find(target); // 1
    
    if (prev_node == nullptr) { // target을 못 찾을 경우
        return false;
    }
    if (prev_node == tail) { // 맨 뒤에 삽입하게 되는 경우
        insert_end(element);
        return true;
    }

    
    Node* new_node = new Node(element); // 2
    
    if (head == nullptr) { // 빈 리스트인 경우
        tail = new_node;
    }
    
    new_node->next = prev_node->next; // 3
    new_node->prev = prev_node; // 4
    prev_node->next = new_node; // 5
    new_node->next->prev = new_node; // 6
    
    return true;
}
```

물론, 역방향(특정 노드 앞에 삽입)도 가능하지만,
이 글에서는 다루지 않을게.
그건 진짜 정반대로만 하면 돼.

1. 삽입할 지점 찾기
2. 새 노드 생성
3. 새 노드의 `prev`를 `next` 노드의 `prev`로 변경
4. 새 노드의 `next`를 `prev` 노드의 `next`(`next` 노드)로 변경
5. `prev` 노드의 `next`를 새 노드로 변경
6. `next` 노드의 `prev`을 새 노드로 변경

코드와 그림은 안 올릴거임.

### 3-3. 기존 노드 삭제

이것도 삽입과 같이 세 가지 경우로 나눌 수 있어.

1. 맨 앞의 노드 삭제
2. 맨 끝의 노드 삭제(사실상 `tail` 포인터를 이용하는 맨 앞 삭제)
3. 중간 노드 삭제

첫 번째인 맨 앞의 노드 삭제부터 보자면,

1. `head`가 가리키던 노드를 `target`으로 미리 저장
2. `head` 포인터를 `head`가 가리키고 있던 노드의 `next` 포인터로 변경
3. `next` 노드의 `prev` 포인터 `nullptr`로 무효화
4. 저장했던 `target`이 가리키는 기존 첫 노드 삭제

이렇게 해주면 돼.


1.

```text
               +----------------------+  --->  +----------------------+  ---> 
[ head ] --->  | nullptr | data 0 | next |      | prev | data 1 | next |       ...
               +----------------------+  <---  +----------------------+  <---
                         ^
                         |
                      [ target ]
```

2.

```text
                                          +----------------------+  ---> 
[ head ] -------------------------------> | prev | data 1 | next |       ...
                                          +----------------------+  <---
                                                    ^
                                                    |
               +-------------------------+          |
[ target ] --> | nullptr | data 0 | next | ---------┘
               +-------------------------+
```

3.

```text
                                          +-------------------------+  ---> 
[ head ] -------------------------------> | nullptr | data 1 | next |       ...
                                          +-------------------------+  <---


               +-------------------------+
[ target ] --> | nullptr | data 0 | next |
               +-------------------------+
```

4.

```text
                                          +-------------------------+  ---> 
[ head ] -------------------------------> | nullptr | data 1 | next |       ...
                                          +-------------------------+  <---


               [ target가 가리키던 data 0 노드 삭제됨 ]
```


```cpp
bool DLList::delete_front() {
    if (head == nullptr) { // 빈 리스트일 때
        return false;
    }

    Node* target = head; // 1
    if (head == tail) { // 노드가 한 개 뿐인 경우
        head = nullptr;
        tail = nullptr;
        delete target;
        
        return true;
    }
    
    head = target->next; // 2
    head->prev = nullptr; // 3
    
    delete target; // 4
    
    return true;
}
```

맨 끝의 노드 삭제는 맨 앞의 노드 삭제의 정반대일 뿐이라 그림과 구현은 생략할게.

1. `tail`을 가리키던 노드를 `target`으로 저장
2. `tail` 포인터를 `tail`이 가리키고 있던 노드의 `prev`로 변경
3. `prev` 노드의 `next` 포인터를 `nullptr`로 무효화
4. `target` 노드 삭제

두 번째로 중간 노드 삭제를 보자면,

1. 삭제할 노드 탐색
2. 삭제할 노드의 `prev` 노드의 `next` 포인터를 삭제할 노드의 `next` 포인터로 변경

```cpp
bool DLList::delete_node(int target){
    if (head == nullptr) { // 빈 리스트일 때 처리
        return false;
    }
    
    Node* target_node = find(target); // 1
    
    if (target_node == nullptr) { // 노드를 찾지 못했을 때 처리
        return false;
    }
    if (head == tail) { // 노드가 하나뿐일 때 처리
        head = nullptr;
        tail = nullptr;
        delete target_node;
        return true;
    }
    if (target_node == head){ // 삭제할 노드가 첫 노드일 때 처리
        return delete_front();
    }
    if (target _node == tail) { // 삭제할 노드가 마지막 노드일 때 처리
        return delete_end();
    }
    
    target_node->prev->next = target_node->next; // 2
    target_node->next->prev = target_node->prev; // 3
    
    delete target_node; // 4
    
    return true;
}
```

### 3-4. 소멸자와 전체 메모리 해제

이중 연결 리스트도 단일 연결 리스트와 같이
소멸자에서 리스트 객체 뿐만 아니라 모든 노드를 메모리 해제해줘야해.

```cpp
DLList::~DLList(){
    Node* current = head; 
    while (current != nullptr) { 
        Node* next_node = current->next; 
        delete current; 
        current = next_node; 
    }
    head = nullptr;
    tail = nullptr;
}
```

### 3-5. 복사 생성자와 깊은 복사

전에 말했듯이, 
연결 리스트에서는 그냥 리스트 객체를 복사한다면 
리스트 객체는 복사되지만
`head`와 `tail` 포인터만 복사되어
노드들은 복사되지 않고 두 리스트 객체가 같은 노드들을 가리키는
얕은 복사(shallow copy)가 실행돼.

```text
(얕은 복사)

list1.head -┐
            ├──> [A] <-> [B] <-> [C]
list2.head -┘
```

그래서 별도로 깊은 복사를 수행하도록 복사 생성자와 복사 대입 연산자를 구현해주어야 해.

```text
(깊은 복사)

list1.head ---> [A] <-> [B] <-> [C]

list2.head ---> [A] <-> [B] <-> [C]
                (서로 다른 노드들)
```

물론 이건 단일 연결 리스트에도 적용되고.

```cpp
class DLList {
private:
    // ...
public:
    DLList() : head(nullptr), tail(nullptr) {
    }

    DLList(const DLList&);
    DLList& operator=(const DLList&);

    ~DLList();

    // ...
};
```

(깊은 복사를 수행하는 복사 생성자 예시)

```cpp
DLList::DLList(const DLList& other) {
    head = nullptr;
    tail = nullptr;
    
    Node* current = other.head;
    
    while (current != nullptr) {
        insert_end(current->data);
        current = current->next;
    }
}
```

(깊은 복사를 수행하는 복사 대입 연산자 예시)
(메모리 할당 실패에 대한 강한 예외 처리까지는 다루지 않음)

```cpp
// 소멸자와 같음, 할당된 모든 노드를 지우는 함수
void DLList::clear(){ 
    Node* current = head; 
    while (current != nullptr) { 
        Node* next_node = current->next; 
        delete current; 
        current = next_node; 
    }
    head = nullptr;
    tail = nullptr;
}
```

```cpp
DLList& DLList::operator=(const DLList& other) {

    if (this == &other) { // 자기 자신과의 대입 연산 확인
        return *this;
    }

    clear(); // 기존의 리스트에 할당되어있던 노드들 해제

    // 깊은 복사
    Node* current = other.head;
    while (current != nullptr) {
        insert_end(current->data);
        current = current->next;
    }

    return *this;
}
```

### 3-6. 대략적인 시간복잡도

- 인덱스 접근 : 최악의 경우 마지막 노드까지 순회해야하므로 $O(n)$
- 순차 탐색 : 최악의 경우 모든 노드를 전부 순회해야하므로 $O(n)$
- 맨앞 삽입 : 고정된 횟수의 포인터 연산만 수행하므로 $O(1)$
- 중간 삽입 : 최악의 경우 모든 노드를 다 돌아야하므로 $O(n)$(위치를 알고 있는 경우 $O(1)$)
- 중간 삭제 : 최악의 경우 모든 노드를 다 돌아야하므로 $O(n)$(위치를 알고 있는 경우 $O(1)$)

## 4. 단일 연결 리스트와의 차이

단일 연결 리스트와의 차이는,

첫 번째로 다음 노드를 가리키는 `next` 포인터에 더해서
이전 노드를 가리키는 `prev` 포인터까지 가지기 때문에 앞뒤 양방향으로 노드 사이를 이동할 수 있다는 점이야.

두 번째로 `prev` 포인터가 있기 때문에 탐색 중간에 이전 노드로도 이동할 수 있어서,
특정 위치에서의 삽입과 삭제가 더 쉽고 빠르다는 점이야.
좀 더 자세히 말하자면, `prev` 포인터가 있어서 특정 노드 앞에 삽입이 쉽다는거야.

세 번째로 단일 연결 리스트보다 하나의 노드에 필요한 메모리 공간이 더 크다는 점이야.
단일 연결 리스트와 다르게 `prev` 포인터까지 필요하니까.

## 5. 요약 정리

1. 이중 연결 리스트는 각 노드가 이전 노드와 다음 노드를 가리켜,
이전 노드로 이동할 수 있는 선형 자료구조이다.
2. 첫 노드의 주소는 `head` 포인터로 가지고,
마지막 노드의 주소는 `tail` 포인터로 가질 수 있다(이건 단일 연결 리스트에도 해당).
3. 원하는 노드를 찾으려면 `head`나 `tail` 포인터의 노드부터 다음 / 이전 노드로
순차적으로 탐색할 수 있다.
4. 삽입할 때는 `next` 포인터와 `prev` 포인터 둘 모두 신경을 써줘야 하고,
포인터 변경 순서에 주의해야한다.
5. 삭제할 때는 삭제할 노드와 이전 노드, 다음 노드의 정보를 이용해서
이전 노드와 다음 노드의 포인터를 교차한다.
6. 동적으로 생성한 모든 노드는 소멸자에서 순차적으로 해제해주어야한다.
7. 복사할 때 깊은 복사(deep copy)를 수행하기 위해서
별도의 복사 생성자 / 복사 대입 연산자를 구현해주어야한다(이건 단일 연결 리스트에도 해당).
