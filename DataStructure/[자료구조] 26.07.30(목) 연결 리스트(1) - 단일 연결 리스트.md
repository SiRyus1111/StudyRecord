## 1. 연결 리스트의 필요성

일단 여기서부터 천천히 짚어보자.

연결 리스트가 굳이 왜 필요한지를 알기 위해서 튜토리얼 느낌으로..

동적 배열(`std::vector` 등)은 중간에 새로운 원소를 삽입하려면
삽입할 위치 뒤에 있는 원소들을 한 칸씩 뒤로 이동시켜야만 해.

```text
[A][B][C][D]

B와 C 사이에 X 삽입 

[A][B][ ][C][D] 
       ↑  →  →
       X
```

원소의 개수가 많다면 이동해야하는 원소도 많아지겠지.

연결 리스트는 각각의 원소를 별도의 노드로 만들고 포인터를 사용해서 연결해서,

- 새로운 노드가 필요할 때마다 동적으로 새로운 노드를 생성할 수 있고,
- 삽입할 위치의 앞 노드를 이미 알고 있다면 포인터 연결만 변경해서 새로운 노드를 삽입할 수 있어.

물론 연결 리스트가 배열보다 항상 좋은건 아니야.

일단 원하는 위치의 원소에 바로 접근할 수 없기 때문에
임의 접근(Random Access) 성능이 떨어지고,

각 노드가 다음 노드의 주소를 저장하기 위한 추가적인 메모리도 필요해져.

이렇게,
배열과 연결 리스트는 서로 다른 장단점을 가진 자료구조인거야.

- 배열 
  - 인덱스 접근에 $O(1)$, 중간 삽입에 $O(n)$
- 연결 리스트 
  - 인덱스 접근에 $O(n)$, 중간 삽입 자체에는 $O(1)$(삽입할 인덱스를 찾는 것까지 포함하면 $O(n)$)
  
이렇기 때문에,
삽입 / 삭제할 노드의 위치를 이미 알고있고,
삽입 / 삭제의 원소 이동 비용을 피하고 싶을 때
연결 리스트를 사용하는걸 고려해볼 수 있어.

## 2. 단일 연결 리스트의 기본 개념들

단일 연결 리스트란,
앞의 노드가 계속 뒤의 노드를 가리키는 형식의
**단방향**의 포인터로 구현된 연결 리스트를 말해.

각 노드는 대략 이렇게,

```cpp
class Node {
public:
    int data;
    Node* next;
};
```

해당 노드의 저장되어있는 데이터를 나타내는 `data`와
다음 노드를 가리키는 포인터인 `next`로 구현할 수 있어.

이 노드 여러개를 `next` 포인터로 연결하면 하나의 리스트가 만들어져.

```text
[ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]
```

첫 번째 노드는 두 번째 노드를 가리키고,
두 번째 노드는 세 번째 노드를 가리켜.

마지막 노드 뒤에는 더이상 노드가 없기 때문에
마지막 노드의 `next` 포인터에는 `nullptr`가 저장돼.

그리고 첫 노드의 주소는 `head` 포인터에 저장해서,
`head` 포인터만 있으면 해당 연결 리스트의 모든 원소에 접근할 수 있게 되지.

```text
[ Head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]
```

결국 이런 구조가 돼.

그리고 삽입 연산같은 경우,

```text
[ Head ] ---> [ data 1 | next ] -×-> [ data 2 | next ] ---> [ data 3 | nullptr ]
                         |               ^
                         |               |
                         └── [ data 4 | next ] 
```

이렇게 

1. 삽입할 노드의 `next` 포인터를 삽입할 위치의 다음 노드(`data 2`가 있는 노드)로 이어주고
2. 삽입할 위치의 전 노드(`data 1`이 있는 노드)의 `next` 포인터를 삽입할 노드로 이어주면 돼.

삭제 연산같은 경우,

```text
[ Head ] ---> [ data 1 | next ] -×-> [ data 2 | next ] -×-> [ data 3 | nullptr ]
                         |                                      ^
                         |                                      |
                         └──-------------------------------------
```

이렇게

1. 삭제할 위치의 전 노드의 `next` 포인터를 삭제할 노드 다음 노드로 이어주고
2. 삭제할 노드를 삭제해버리면 돼.

### 2-1. ADT

단일 연결 리스트의 ADT로는,

- 리스트의 특정 위치에 새로운 원소를 삽입(insert)
  - 앞 / 뒤 / 중간
- 리스트의 특정 위치의 원소를 삭제(delete)
  - 앞 / 뒤 / 중간
- 리스트의 특정 위치의 원소를 반환(get)
- 리스트가 비어있는지 확인(isEmpty)
- 리스트의 특정 원소 탐색(find)
- 리스트의 특정 위치의 원소 다른 원소로 대체(replace)
- 리스트 안의 원소 갯수 반환(size)

이 정도가 있겠지.

바로 뒤의 구현 파트에서는

- 원소 특정 위치에 삽입(insertion)
- 특정 위치의 원소 삭제(deletion)
- 특정 원소 탐색(search)

이렇게 세 가지를 중점으로 살펴볼게.

## 3. 단일 연결 리스트의 구현

### 3-1. 노드와 리스트 클래스의 기본 구조

일단, 기본적인 노드와 클래스의 구현부터 볼게.

```cpp
// 연결 리스트 노드
class Node {
public:
    int data;
    Node* next;
    
    Node(){ // 노드가 아무런 옵션 없이 생성되었을 때는
        data = 0; // data를 0으로 초기화하고
        next = nullptr; // next를 nullptr로 초기화
    }
    Node(int element){ // 노드가 원소와 함께 생성되었을 때는
        data = element; // data를 입력받은 원소로 초기화
        next = nullptr;
    }
};
```

일단 노드야.

앞서 설명한 

- 저장되어있는 데이터 : `data`
- 다음 노드를 나타내는 포인터 : `next`

가 있고,
생성자가 두 개 있어.

아무 매개변수도 안 넣은 경우에는 
해당 노드의 데이터도, 다음 노드도 입력받지 않았으니 
`next = nullptr`로 초기화해.

만약 `data`에 넣을 값(`element`)을 넣었다면
`data = element`로 초기화해줘.

클래스는 대략 이렇게 구현할 수 있어.

```cpp
// 연결 리스트 클래스
class SLList{
private:
    Node* head;
public:
    SLList(){ // 아무것도 입력받지 않았을 때는
        head = nullptr; // head를 nullptr로 초기화
    }
    ~SLList();
    
    Node* find(int element);
    
    void insert_front(int element);
    bool insert_node(int target, int element);
    
    bool delete_front();
    bool delete_node(int target);
};
```

앞서 설명했듯, 첫 노드의 주소를 나타내는 `head` 포인터를 멤버로 들고있어.

### 3-2. 노드 순회 및 탐색

이게 전에 목차에선 제일 마지막에 적었지만,
제일 간단해서.
이거 먼저 할게.

탐색은 간단해.

1. 현재 노드를 본다.
2. `data`가 찾는 값인지 확인한다.
3. 찾는 값이면 해당 노드를 반환하고 아니라면 다음 노드로 넘어간다.

딱 이렇게야.

그리고, 끝에 도달했다는건 
`current == nullptr`로 판별해.

`current == nullptr`라는건 바로 앞의 노드의 `next` 포인터가 `nullptr`이라는 뜻이니까.
그렇다면 모든 노드를 확인했다는걸 알 수 있지.

1.
```text
[ Head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]
                 ^
                 |
                 |
               current(Head 포인터로 가리키는 값과 동일함)
```
2. 
```text
[ Head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]
                 ^
                 |
                 |
             target == data 1인지 확인
```
3. 
```text
[ Head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]
                          ^
                          |
                          |
           아니라면 이 next 포인터를 이용해서 다음 노드로 넘어간다.
```

코드도 단순해.

```cpp
Node* SLList::find(int target) {
    Node* current = head;
    while (current != nullptr) {
        if (current->data == target) {
            return current;
        }
        
        current = current->next;
    }
    
    return nullptr;
}
```

1. `current`로 현재 노드를 가리킨다.
2. 현재 노드의 `data`가 찾는 값과 같은지 확인한다.
3. 같지 않다면 `current`를 `current->next`로 갱신해서 다음 노드로 이동한다.
4. 값을 찾는다면 해당 노드의 주소를 반환한다.
5. `current = nullptr`, 즉 마지막 노드까지 도달하면 리스트에 해당 값이 없다는 뜻이므로 nullptr를 반환한다.

이런 동작이야.

최악의 경우 마지막 노드까지 전부 확인해야하기 때문에,
시간 복잡도는 $O(n)$이야.

### 3-3. 새로운 노드 삽입

삽입은 두 가지 경우로 보자.

1. 맨 앞에 새로운 노드 삽입 -> 사실상 head만 바꿔주면 됨(쉬움)
2. 특정 노드 뒤에 새로운 노드 삽입 -> 특정 노드를 찾은 후 바꿔줘야함(상대적으로 어려움)

일단 첫 번째, 맨 앞에 새로운 노드를 삽입하는 경우부터.

맨 앞에 새로운 노드 삽입은,

1. 새 노드 생성
2. 새 노드의 `next`를 `head`로 변경
3. `head`가 새 노드를 가리키도록 변경

이렇게 해주면 돼.

1. 
```text
[ Head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]
            
              [ data 4 | nullptr ]
```
2. 
```text
[ Head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]             
                   ^
                   |
      [ data 4 | next ]
```
3. 
```text
[ Head ]      [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]      
    |              ^
    |              |
    └> [ data 4 | next ]
```

```cpp
void SLList::insert_front(int element){
    Node* new_node = new Node(element);
    
    new_node->next = head;
    head = new_node;
}
```

두 번째로, 특정 노드 뒤에 새로운 노드를 삽입하는 경우.

특정 노드 뒤에 새로운 노드 삽입은,

1. 먼저 삽입할 지점을 찾은 후
2. 새 노드 생성
3. 새 노드의 `next`를 삽입할 노드 이전 노드의 `next` 포인터로 변경
4. 삽입할 노드 이전 노드의 `next` 포인터를 새 노드를 가리키도록 변경

이렇게 해주면 돼.

1.
```text
[ Head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]
                  ^
                  |
            data 1 이후에 삽입
```
2. 
```text
[ Head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]
               
               [ data 4 | nullptr ]
```
3.
```
[ Head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]
                                        ^
                                        |
                            [ data 4 | next ]
```
4.
```text
[ Head ] ---> [ data 1 | next ]      [ data 2 | next ] ---> [ data 3 | nullptr ]
                            └---┐       ^
                                ↓       |
                            [ data 4 | next ]
```

```cpp
bool SLList::insert_node(int target, int element) {
    Node* previous = find(target); // 노드 찾는데는 이전에 구현해두었던 find를 씀
    
    if (previous == nullptr) return false; // 삽입할 지점을 찾지 못한경우 false 반환
    
    Node* new_node = new Node(element);
    
    new_node->next = previous->next;
    previous->next = new_node;
    
    return true; // 성공했으면 true 반환
}
```

여기서 포인터를 변경하는 순서가 중요한데,
`previous`(삽입할 노드의 전 노드) `next`를 먼저 변경해버리면
새 노드의 `next`를 설정할 때 이전 노드의 값을 참고할 수 없게 되기 때문이야.

```text
[ Head ] ---> [ data 1 | next ]      [ data 2 | next ] ---> [ data 3 | nullptr ]
                            └---┐       
                                ↓       
                            [ data 4 | nullptr ] <-- 이 포인터는 어디서 얻어와야할까?
```

### 3-4. 기존 노드 삭제

삭제도 두 가지 경우로 나눌 수 있어.

1. 맨 앞의 노드 삭제 : `head` 포인터만 움직이고 삭제하면 됨
2. 중간의 노드 삭제 : 포인터 두 개를 움직이며 삭제하기 때문에 난이도가 어려움

일단 첫 번째. 맨 앞의 노드를 삭제하는 방법을 보자.

1. `head`를 `head`가 가리키고 있는 노드의 `next`로 변경
2. 기존에 `head`가 가리키고 있던 노드 삭제

이렇게 해주면 돼.

1.
```text
[ Head ]      [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]
    |                                    ^
    |                                    |
    └------------------------------------┘
```
2. 
```text
[ Head ]                             [ data 2 | next ] ---> [ data 3 | nullptr ]
    |                                    ^
    |                                    |
    └------------------------------------┘
```

```cpp
bool SLList::delete_front(){
    if (head == nullptr) { // 빈 리스트일 때 처리
        return false;
    }

    Node* target = head;
    head = target->next;
    
    delete target;
    
    return true;
}
```

중간 노드 삭제는 좀 복잡해.

이게 지금까지는 많아봐야 한 개의 포인터를 움직였는데,
이 중간 노드 삭제는 두 개의 포인터를 계속 움직이거든.

삭제할 노드의 이전 노드를 알아야하기 때문이야.
삭제할 노드의 이전 노드는 방금 맨 앞의 노드를 삭제하는 과정에서 사용되는
`head`와 같은 역할을 수행해.

1. 삭제할 노드의 이전 노드를 나타내는 포인터와 삭제할 노드를 나타내는 포인터를 이동시키며
삭제할 노드를 나타내는 포인터가 삭제한 노드를 가리킨다면 멈춤
2. 삭제할 노드의 이전 노드의 `next` 포인터를 삭제할 노드의 `next` 포인터로 변경
3. 삭제할 노드를 삭제

이건 진짜 그림 없으면 이해가 힘들어서..

1. 
```text
삭제할 노드 = 2번 노드(data 2)

[ Head ] ---> [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]
                   ^                    ^
                   |                    |
                previous             current
```
2. 
```text
                           ┌-----------------------------------┐
                           |                                   ↓
[ Head ] ---> [ data 1 | next ]      [ data 2 | next ] ---> [ data 3 | nullptr ]
                   ^                    ^
                   |                    |
                previous             current      
```
3.
```text
                           ┌-----------------------------------┐
                           |                                   ↓
[ Head ] ---> [ data 1 | next ]                             [ data 3 | nullptr ]
                   ^                    ^
                   |                    |
                previous             current(삭제됨)    
```

```cpp
bool SLList::delete_node(int target) {

    if (head == nullptr) { // 빈 리스트일 때 처리
        return false;
    }

    Node* previous = head;
    Node* current = head->next;
    
    while (current != nullptr) {
         if (current->data == target) {
             previous->next = current->next;
             delete current;
             
             return true;
         }
         
         previous = current;
         current = current->next;
    }
    
    return false;
}
```

### 3-5. 소멸자와 전체 메모리 해제

그리고 이전 글에서 이렇게 포인터로 연결된 객체의 소멸자 이야기를 했었는데,

```text
[ 삭제됨 ]    [ data 1 | next ] ---> [ data 2 | next ] ---> [ data 3 | nullptr ]
              (head를 삭제했지만 이 노드들은 메모리 해제가 되지 않음)
```

연결 리스트에서는 이렇게 `head` 포인터를 지운다고 모든 노드가 삭제되는게 아니라서,

해당 연결 리스트 객체의 소멸자에서 앞에서부터 차근차근 모든 노드를 지우도록 구현해줘야해.

```cpp
SLList::~SLList(){
    Node* current = head; 
    while (current != nullptr) { 
        Node* next_node = current->next; 
        delete current; 
        current = next_node; 
    }
    head = nullptr; // head 포인터까지 무효화!
}
```

### 3-6. 대략적인 시간복잡도

- 순차 탐색 : 최악의 경우 모든 노드를 다 돌아야하므로 $O(n)$
- 맨앞 삽입 : 고정된 횟수의 포인터 연산만 수행하므로 $O(1)$
- 중간 삽입 : 최악의 경우 모든 노드를 다 돌아야하므로(삽입 자체는 $O(1)$) $O(n)$
- 맨앞 삭제 : 고정된 횟수의 포인터 연산만 수행하므로 $O(1)$
- 중간 삭제 : 최악의 경우 모든 노드를 다 돌아야하므로(삭제 자체는 $O(1)$) $O(n)$

이렇게 되겠네.

### 3-7. 지금까지 간과한 부분들

사실, 지금까지의 구현 예시에선 예외처리를 다루지 않았어.

대표적으로,

- 빈 리스트에 삽입 / 삭제하는 경우
- 유일한 노드를 삭제하는 경우
- 맨 뒤에 노드를 삽입하는 경우

이런 경우들이 있는데,

이번 글에서는 연결 리스트에 대한 튜토리얼 느낌으로,
이런 부분들은 직접적으로 다루지 않았어.

그리고 이 구현들은 명확한 한계가 있어.

- 같은 값이 여러개라면 처음 발견한 노드만 삽입 / 삭제의 기준으로 사용
- 인덱스를 기준으로 삽입 / 삭제하지 않음
- 리스트를 복사하는 경우를 고려하지 않음(별도의 복사 생성자 구현하지 않음)
- 실제 컨테이너처럼 템플릿(`int`만 지원) / 이터레이터 / 예외 안전성 등은 지원하지 않음

그래서 이번 글은 완전한 연결리스트 구현이라기보단,
연결 리스트의 개념과 각 연산의 구현을 대략적으로 알아보는 느낌이라고 생각해줘.
