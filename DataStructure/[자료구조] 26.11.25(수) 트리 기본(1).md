## 1. 트리의 정의와 용어

트리는
한 개 이상의 노드로 이루어진 유한 집합으로써
노드 중에는 최상위 노드인 루트 노드가 하나 있고
나머지 노드들은 $n \geq 0$개의 부분 집합(서브 트리)으로 분할될 수 있는 
자료 구조라고 할 수 있어.
(그 부분 집합들도 트리고. 재귀적 구조라고 할 수 있지.)

한 노드의 서브트리의 수를 그 노드의 차수(degree)라고 할 수 있고,
차수가 0인 노드를 리프(leaf) 노드라고 해.
트리의 차수(degree of a tree)란 그 트리에 있는 노드들의 최대 차수라고 하고.

한 노드의 서브트리의 루트 노드들을 해당 노드의 자식(children) 노드라고 하고,
해당 노드는 서브트리의 루트 노드들의 부모(parent) 노드라고 할 수 있어.
부모가 같은 자식들을 형제(sibling) 노드라고 하고,
형제들의 순서는 일반적으로 구분하지 않아.
한 노드의 조상(ancestor) 노드들은 루트에서부터 해당 노드에 이르는 모든 노드라고 할 수 있어.
조상에는 자기 자신은 일반적으로 안 들어가.

레벨(level)이란 루트 노드로부터 얼마나 떨어져 있는지를 나타내는 계층 번호라고 할 수 있어.
루트 노드는 보통 1레벨이라고 정의해.
해당 노드의 레벨이 $n$이라면, 자식 노드의 레벨은 $n+1$이 되는 식이지.

트리의 높이(height) / 깊이(depth)란 해당 트리에 속한 노드의
최대 레벨이라고 할 수 있고.

## 2. 트리의 표현

트리는 다양한 방식으로 표현될 수 있어.

### 2-1. 리스트 표현

일단 리스트!
이걸 어떻게 설명해야하는지는 모르겠는데,
트리의 각 노드 간의 관계를 연결 리스트로 표현할 수 있어.

```text
[A] -> [] -> [] -> []
       |     |      |
       |     |      v
       |     |     [D] -> [] -> [I] -> [J|0]
       |     v             |
       |     [C] -> [G|0]  v
       v                  [H] -> [M|0]
      [B] -> [] -> [F|0]
             |
             v
            [E] -> [K] -> [L|0]
```

- A -> B, C, D
- B -> E, F
- C -> G
- D -> H, I
- E -> K
- F -> `nullptr`(`0`), 해당 노드는 리프 노드
- G -> `nullptr`(`0`), 해당 노드는 리프 노드
- H -> M
- I -> J
- J -> `nullptr`(`0`), 해당 노드는 리프 노드
- K -> L
- L -> `nullptr`(`0`), 해당 노드는 리프 노드
- M -> `nullptr`(`0`), 해당 노드는 리프 노드

이런 식으로..

두 번째로 데이터 + 자식 노드 포인터로 각 노드를 표현하는 방법!
이건 설명이 간단해.
예를 들어,

```cpp
struct Node {
    int data;
    Node* child1;
    Node* child2;
    Node* child3;
    Node* child4;
    // ...
};
```

이런 식으로 각 노드를 표현하는거지.
근데 이 방법의 단점은
웬만해서는 편의상 모든 노드의 크기를 동일하게 사용해야되기 때문에
트리의 차수가 $k$면 모든 노드의 `child` 포인터가 $k$개여야해서
메모리 낭비가 된다는거야.

### 2-2. 왼쪽 자식-오른쪽 형제 표현

한 노드를 데이터 / 자식 / 형제로 표현하는 방법이야.
구조체는 대략 이렇겠지?

```cpp
struct Node {
    int data;
    Node* child;
    Node* sibling;
};
```

왼쪽 포인터로는 자식 노드를 가리키고,
오른쪽 포인터로는 형제 노드를 가리키는 방법이야.
그리고 자식 노드 / 형제 노드를 가리키는 방향은 한 방향으로만 가리키지.
(순환 참조 안한다는 뜻)

이러면 뭔가 기묘한 형태이긴 해도?
트리를 표현할 수 있어.

장점은 자식 노드가 여러 개여도 
각 노드의 두 개의 포인터만으로 트리를 표현할 수 있다는 점이야.
단점은 부모 노드에서 두 번째 이상의 자식 노드에 접근할 때
추가적인 연산이 필요하다는 점이라고 할 수 있고..

자식이 없다면 자식을 나타내는 왼쪽 포인터를 `nullptr`로 놓고,
더 이상 형제가 없다면 형제를 나타내는 오른쪽 포인터를 `nullptr`로 놓고..

여기서 중요한게

> 이 표현을 사용하면 모든 노드가 다른 노드를 가리키는 포인터를 두 개만 가지고도
> 차수가 2가 아닌 트리까지 표현할 수 있다는 거야.

이게 진짜 중요해.

어떤 차수를 가진 트리든 차수가 2인 트리로 표현할 수 있다는거지.

### 2-3. 차수가 2인 트리 표현

이거는 되게 간단해.

```cpp
struct Node {
    int data;
    Node* left_child;
    Node* right_child;
}
```

이렇게 놓으면 끝!
방금 전의 왼쪽 자식-오른쪽 형제 표현에서
오른쪽 형제를 오른쪽 자식으로 바꾼 것 뿐이야.

그리고 이런 트리를 이진 트리라고 하지.

앞의 왼쪽 자식-오른쪽 형제 표현을 이진 트리로 고쳐보자면,
한 노드의 왼쪽 노드는 해당 노드의 자식 노드가 되는거고,
한 노드의 오른쪽 노드는 해당 노드의 형제 노드가 되는거야.

결국 요약하면,

1. 모든 트리는 왼쪽 자식-오른쪽 형제 표현으로 표현할 수 있다.
2. 왼쪽 자식-오른쪽 형제 표현은 차수가 2인 트리로 표현할 수 있다.
3. 즉, 모든 트리는 차수가 2인 트리로 표현할 수 있다.

이렇게 된다는거야.

## 3. 이진 트리

앞에서 왼쪽 자식-오른쪽 형제 표현에서

> 모든 트리는 각 노드의 포인터가 두 개인 트리로 표현할 수 있다

는걸 알았지?

그 말은 즉,

> 모든 트리는 이진 트리로 표현할 수 있다.

라는 말이 돼.

그래서 이진 트리가 중요해.

이진 트리는 앞서 말했듯 차수가 2인 트리야.
즉, 한 노드는 최대 두 개의 자식 노드만을 가진다는거지.

이진 트리의 중요한 점은,
자식의 순서를 구별한다는거야.
왼쪽은 왼쪽, 오른쪽은 오른쪽.
(일반 트리는 안 구분함)

이진 트리의 ADT는 대충 이래.

- `BinaryTree()` 
: 생성자, 빈 이진 트리 객체 생성
- `BinaryTree(Node* bt1, T& item, Node* bt2)`
: 왼쪽 서브트리가 `bt1`, 오른쪽 서브트리가 `bt2`이고
루트 노드가 `item`을 갖는 이진 트리 객체 생성
- `bool` `empty()` 
: 이진 트리 객체가 빈 이진 트리 객체인지 판별
- `Node*` `leftSubTree()` 
: 해당 이진 트리 객체의 왼쪽 서브 트리 반환
- `Node*` `rightSubTree()` 
: 해당 이진 트리 객체의 오른쪽 서브 트리 반환
- `T&` `rootData()`
: 해당 이진 트리 객체의 루트 노드의 데이터를 반환

### 3-1. 이진 트리의 성질

(루트 = 레벨 1 기준)
이진 트리의 레벨 $i$에서의 최대 노드 개수는 $2^{i-1}$개야.

레벨 $1$이면 노드가 한 개(루트 노드)고,

레벨 $i-1$일 때는 최대 노드 개수가 $2^{i-2}$개라 가정하면,
레벨 $i$일 때는 최대 노드 개수가 각 노드의 차수가 2이므로 두 배가 되어
$2^{i-1}$개가 되겠지.

그리고 깊이가 $k$인 이진 트리의 최대 노드 수는
$\sum_{i=1}^{k} 2^{i-1} = 2^{k} - 1$개야.

\+ 포화 이진 트리란,
깊이가 $k$일 때 노드의 수가 $2^{k}-1$개인,
모든 노드에 모든 자식이 있는 이진 트리야.

\+ 완전 이진 트리란,
마지막 레벨을 제외하고 모든 레벨이 빠짐없이 완전히 채워져있으며,
마지막 레벨의 노드는 왼쪽부터 차례로 채워진 트리야.

### 3-2. 이진 트리의 표현

이진 트리는 크게 두 가지 표현 방식을 사용할 수 있어.

첫 번째로, 배열 표현이야.
각 노드의 최대 차수가 2라는 것을 이용한 방법인데,

각 노드의 최대 차수가 2 이상이 될 수 없으니

- $parent(c) = \lfloor c / 2 \rfloor$
  - $c = 1$이라면 루트 노드
- $leftChild(p) = 2 \times p$
  - $n < 2i$이라면 왼쪽 자식 노드는 없음
- $rightChild(p) = 2 \times p + 1$
  - $n < 2i + 1$이라면 오른쪽 자식 노드는 없음

이렇게 인덱싱을 해놓으면
중복되는게 없어서
단순 배열로도 표현할 수 있어.

이 방법은 대부분의 경우 사용되지 않는 인덱스가 있을지 몰라도
어떤 이진 트리도 나타낼 수 있어.

완전 이진 트리의 경우에는 낭비되는 공간이 없으니 이상적이지.

물론 계속 같은 방향의 자식만 있는 편향 이진 트리같은 경우에는
낭비되는 공간이 많겠지만..

그리고 노드 삽입 / 제거가 (바로 뒤에 소개할 방법에 비해) 무겁기도 하고.

그래서 두 번째 방법을 사용해.

이건 말 그대로 포인터로 자식 노드들을 가리키는 방법인데,

```cpp
struct Node {
    int data;
    Node* left;
    Node* right;
    
    Node(const int& _data, Node* _left = nullptr, Node* _right = nullptr)
    : data(_data), left(_left), right(_right){
    
    }
}
```

이런 노드를 사용해.

이런 구조에서는 해당 노드의 부모 노드를 알기 어렵다는 단점이 있기는 하지만,
대부분의 응용에는 적합하대.

물론 부모 노드를 알아야할 필요가 있다면
따로 `Node*` `parent` 포인터를 추가하면 그만이고..

### 3-3. 이진 트리 순회

이진 트리에는 다양한 연산을 할 수 있어.

그 중에 하나는 순회(traversal)야.
말 그대로 트리의 모든 노드를 한 번 씩 방문하는거지.

그리고 방문마다 각 노드에 대한 연산을 수행하기도 하고..

그리고 이런 관점으로 보는게 좋아.
루트 노드 / 왼쪽 서브트리 / 오른쪽 서브트리를 각 객체로 놓고
어느 순서로 순회할 것인가.

이건 되게 재귀적으로 적용돼.

왼쪽 서브트리의 루트 노드 관점에서 보면 
또 왼쪽 서브트리 / 오른쪽 서브트리로 나뉘어지는 느낌이지.

그리고 보통 왼쪽 서브트리를 먼저 순회하는 경우가 많아.

순회 방식으로는

- 중위 순회 : 왼쪽 서브트리 -> 루트 노드 -> 오른쪽 서브트리
- 전위 순회 : 루트 노드 -> 왼쪽 서브트리 -> 오른쪽 서브트리
- 후위 순회 : 왼쪽 서브트리 -> 오른쪽 서브트리 -> 루트 노드

가 있어.

중위 순회부터 보자면,

```cpp
void inorder(Node* node) {
    if (node == nullptr) {
        return;
    }
	inorder(node->left);
    // 현재 노드 방문
    inorder(node->right);
}
```

이렇게 재귀로 짤 수 있어.

이 순회 방식은 더 이상 진행할 수 있을 때 까지 왼쪽 방향으로 내려간 후,
그 노드를 방문하고 오른쪽 자식 노드로 이동한 뒤 계속해.

전위 순회를 보자면,

```cpp
void preorder(Node* node) {
    if (node == nullptr) {
        return;
    }
    // 현재 노드 방문
    preorder(node->left);
    preorder(node->right);
}
```

이렇게 재귀로 짤 수 있어.

이 순회 방식은 노드를 먼저 방문하고 왼쪽으로 가서 계속해.
왼쪽으로 갈 수 없는 경우에는 오른쪽으로 이동해서 계속하고.

후위 순회를 보자면,

```cpp
void postorder(Node* node) {
    if (node == nullptr) {
        return;
    }
    postorder(node->left);
    postorder(node->right);
    // 현재 노드 방문
}
```

이렇게 재귀로 짤 수 있어.

이 순회 방식은 더 이상 진행할 수 없을 때까지 왼쪽으로 내려간 후에,
더이상 내려갈 수 없으면 오른쪽으로 내려가서 계속해.
그리고 왼쪽과 오른쪽 둘 다 계속할 수 없으면 해당 노드에 방문 처리를 해.

#### 3-3-1. 반복문을 이용한 중위 순회

사실, 재귀 말고도 스택과 반복문을 이용해서 순회를 할 수 있어.

```cpp
void nonrecInorder() {
    std::stack<Node*> stack;
    Node* current = root;
    while (true) {
        while (current != nullptr) {
            stack.push(current);
            current = current->left;
        }
        
        if (stack.empty()) return;
        
        current = stack.top();
        stack.pop();
        
        // 현재 노드 방문
        
        current = current->right;
    }
}
```

이런 식으로.

결국 스택이 LIFO니, 지나갔던 노드들을 순서대로 기록해둘 수 있어서.

책에서는 이터레이터를 쓰는 것도 나오는데,
그건 중요하지 않아서 생략했어.

#### 3-3-2. 레벨 순서 순회

루트로부터 가까운 노드부터 순회하는 방법이야.
보통 같은 레벨의 노드는 왼쪽부터 순회해.

이건 큐를 이용해서 순회할 수 있어.

```cpp
void levelorder() {
    std::queue<Node*> queue;
    queue.push(root);
    
    while (!queue.empty()) {
    	Node* node = queue.front();
        queue.pop();
    
        // 현재 노드 방문
        
        if (node->left != nullptr) {
            queue.push(current->left);
        }
        if (node->right != nullptr) {
            queue.push(current->right);
        }
        
    }
}
```

큐의 FIFO 특성을 이용해서,
상위 레벨 노드들을 (왼쪽부터) 먼저 큐에 넣고,
그 순서대로 탐색을 하는거야.

#### 3-3-3. 트리 복사

이것도 사실상 순회인데,
중요한건 재귀적으로 반환하는 값이 노드에 대한 포인터라는거야.

이렇게 하면 돼.

```cpp
Node* copy(Node* node) {
    if (node == nullptr) {
        return nullptr;
    }
    
    Node* new_node = new Node(node->data);
    new_node->left = copy(node->left);
    new_node->right = copy(node->right);
    
    return new_node;
}
```

전위 순회로,

- 노드를 생성하고
- 왼쪽 자식 노드를 재귀적으로 연결하고
- 오른쪽 자식 노드를 재귀적으로 연결하고

하면 돼.

베이스 케이스는 자식 노드가 `nullptr`일 때 
자식 노드 포인터를 그대로 `nullptr`로 하면 되니까
`node == nullptr`이면 `nullptr`를 반환하는 식으로 하면 돼.

#### 3-3-4. 동일성 검사

이건 두 트리가 같은지를 검사하는 그런거야.

이것도 순회로 할 수 있는데,
두 트리를 동시에 순회해야한다는 점이 차이점이지.

```cpp
bool equal(Node* node1, Node* node2) {
	if (node1 == nullptr && node2 == nullptr) {
    	return true;
    }
    if (node1 == nullptr || node2 == nullptr) {
        return false;
    }
    
    bool is_data_equal = node1->data == node2->data;
    bool is_left_equal = equal(node1->left, node2->left);
    bool is_right_equal = equal(node1->right, node2->right);

    return is_data_equal && is_left_equal && is_right_equal;
}
```

이렇게 하면 돼.

일단 두 노드가 둘 다 `nullptr`면 같다는 것이므로 `true`를 반환,
두 노드 중 한 노드만 `nullptr`면 다르다는 것이므로 `false`를 반환
(앞의 둘다 `nullptr`인 경우 검사를 해서 무조건 다름)

그리고 데이터 / 왼쪽 노드 / 오른쪽 노드가 같은지 검사..
왼쪽 노드 / 오른쪽 노드 검사는 재귀로 짜면 돼.

## 4. 요약

1. 트리는 최상위 노드인 루트 노드와 $n \geq 0$개의 서로소인 서브트리로 구성된 자료 구조이다.
2. 모든 트리는 왼쪽 자식-오른쪽 형제 표현으로 이진트리로 표현할 수 있다.
3. 이진트리는 배열 / 포인터를 이용한 연결(링크) 방식으로 표현할 수 있다.
4. 이진트리는 
전위(루트 노드 -> 왼쪽 서브트리 -> 오른쪽 서브트리) / 
중위(왼쪽 서브트리 -> 루트 노드 -> 오른쪽 서브트리) / 
후위(왼쪽 서브트리 -> 오른쪽 서브트리 -> 루트 노드) /
레벨(루트 노드에 가까운 노드부터)로 
순회할 수 있다.
5. 스택을 이용해서 전위 / 중위 / 후위 순회를 할 수 있고
큐를 이용해서 레벨 순서 순회를 할 수 있다.
6. 이진트리에 대한 연산은 루트 노드 / 왼쪽 서브트리 / 오른쪽 서브트리에 대한 연산으로 분해해서
재귀적으로 해결할 수 있다.
