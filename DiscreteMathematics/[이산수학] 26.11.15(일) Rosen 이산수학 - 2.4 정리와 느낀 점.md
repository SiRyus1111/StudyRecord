## 1. 수열

### 정리

1. 수열
    - 수열은 순서 있는 리스트를 나타내는데 사용하는 이산 구조이다.
    - 수열이란, 정수집합의 부분집합으로부터의 집합 $S$로의 함수이다.
      - 정수 $n$의 상을 나타내기 위해서 $a_{n}$을 사용한다.
      - $a_{n}$을 수열의 항(term)이라고 한다.
    - 정수집합은 $n$을 담당하고 집합 $S$는 $a$를 담당하는 느낌이다.
    - 규칙이 있든 없든 간에
    정수집합의 부분집합을 정의역으로,
    수열의 $a_{n}$들에 해당하는 집합 $S$를 공역으로 가지고 있는 함수이다.
    
2. 등비수열
    - 등비수열은 정수집합의 부분집합 $\{1, 2, 3...\}$을 정의역으로 할 때
    $ar^{n-1}$의 형태를 가지는 수열이다.
      - 지수함수와 비슷하지만, 수열은 이산적이다.(값이 뚝뚝 끊긴다.)
    - $a$를 첫 항이라고 하고, $r$을 공비라고 한다.
    
3. 등차수열
    - 등차수열은 정수집합의 부분집합 $\{1, 2, 3...\}$을 정의역으로 할 때
    $a + (n-1)d$의 형태를 가지는 수열이다.
      - 선형함수와 비슷하지만, 수열은 이산적이다.
    - $a$를 첫 항이라고 하고, $d$를 공차라고 한다.

4. 문자열
    - 컴퓨터 과학에서 주로 쓰이는 수열의 형태이다.
    (각 문자는 비트열이기 때문에 수열의 형태가 될 수 있다.)
    - 문자열은 수열로도 표현할 수 있다.

### 느낀 점 & 배운 점

나 뭔가 머리 세게 얻어맞은 느낌이야..

수열이라는게 결국
정수집합의 부분집합에서 집합 $S$로의 함수라는건데,

나 수열을 함수로 생각해본 적이 없었거든ㅋㅋ

좀 상당히 색다른 느낌이야.

결국 수열의 각 항은
함수에다가 각 정수를 넣는 식이니까 그럴만 한 것 같아.

이렇게 보면 배열같은 것도
각 인덱스를 넣으면 결과로 각 인덱스의 데이터가 나오는 느낌으로 보여지는 것 같아.
각 인덱스가 정의역이고, 각 인덱스의 데이터들이 집합 $S$라는 느낌이지.

좀 더 엄밀하게 표현하자면,
각 인덱스가 정의역이고, 
각 인덱스가 표현가능한 값들이 집합 $S$(공역), 
인덱스의 데이터가 치역이라고 할 수 있겠네.

뭐 등비수열 / 등차수열 / 문자열 같은건 이미 잘 알고 있어서 별로 어렵지는 않았어.

## 2. 점화 관계

### 정리

1. 점화(recurrence) 관계
    - 하나 이상의 이전 항들을 통해 다음의 항이 나타내어지는 관계이다.
    - 수열의 항들이 점화 관계를 만족하면 해당 수열을 점화 관계의 해라고 한다.

2. 초기 조건
    - 점화 관계가 효력을 나타내기 시작하는 상에 앞서서 나타나는 항이다.
    - 이 초기 조건이 있어야 점화 관계로 수열을 만들 수 있다.
    - 예 : 피보나치 수열
      - 점화 관계 : $f_{n} = f_{n-1} + f{n-2}$
      - 초기 조건 : $f_{0} = 0$, $f_{1} = 1$
    - 점화 관계와 초기 조건으로 수열의 일반항을 구혀는 것을
    점화 관계를 풀었다, 또는 점화 관계의 해를 얻었다고 표현한다.
    
3. 반복법(iteration)
    - 반복법은 앞의 결과 / 뒤의 결과를 기반으로 반복해서 점화 관계를 적용해서
    점화 관계를 푸는 방법이다.
    - 초기 조건부터 시작해서 점화 관계를 푸는 전향 대입,
    $a_{n}$부터 역으로 시작하는 것을 후향 대입이라고 한다.
    - 반복법을 쓸 수 있을 때는
    수열의 항을 예측할 수 있을 때이다.

### 느낀 점 & 배운 점

이번 파트는 뭔가 익숙했어.

내가 예전에 알고리즘에서 DP(다이나믹 프로그래밍) 문제를 풀 때
점화식이라는걸 썼었거든?

이게 여기서 나온거였구나 싶더라..

결국 DP도 간단히 직관적으로 설명하면
이전의 값들을 저장해서
이전의 값들을 다시 계산하지 않고
다음의 값을 만드는 것이라고 할 수 있잖아?

결국 이 챕터에서 말하는 점화 관계도
수열이 있을 때
하나 이상의 이전 항들로 다음 항이 나타내지는 관계니까..

- DP = 이전 값들을 저장, 이전 값들을 사용해서 다음 값을 만듬
- 점화 관계 = 이전 항들로 다음 항($a_{n}$)을 정의(?)함

## 3. 수열의 합(summations)

### 정리

1. 수열의 합의 기호($\sum$)
    - $\sum$은 수열의 합을 나타내는 기호이다.
    - $\sum_{i = m}^{n} a_{i}$이라고 하면,
    '수열 $a_{i}$의 $i$를 $m$부터 $1$씩 증가시키며 $n$이 되는 때 까지 다 더해라' 라는 뜻이다.
      - $i$를 수열의 합의 인덱스라고 한다.
    - 예 : $\sum_{i = 1}^{3} (2i + 1) = (2 + 1) + (4 + 1) + (6 + 1) = 15$
    - 산술 연산에서의 통상적인 연산 법칙들은 수열의 합에서도 적용될 수 있다.
      - 예 : $\sum_{i = 1}^{n} (a_{i} + b_{i}) = \sum_{i = 1}^{n} (a_{i}) + \sum_{i = 1}^{n} (b_{i})$ 등

### 느낀 점 & 배운 점

이번 챕터도 별게 있을 줄 알았는데 생각보다 별게 없었어.

그냥 수열의 합은 $\sum$으로 쓰고
$\sum_{i=n}^{m} a_{i}$라면 수열 $a_{i}$의 $i$가 $n$일 때 부터 $m$일 때 까지의 합이다.

이게 끝임..

그리고 프로그래밍의 반복문을 수열의 합으로 표현할 수 있다는 것 정도?

$\sum_{i = 1}^{10} a_{i}$는

```cpp
int sum = 0;

for (int i = 1; i <= 10; i++) {
    sum += a[i];

```
