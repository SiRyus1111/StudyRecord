## 1. 집합

### 정리

1. 집합(set)
    - 집합이란 **순서를 고려하지 않은** 서로 다른 개체(object)들의 모임이다.
    - 집합에 속한 개체는 멤버 / 원소라고 부른다.
    (보통 원소라고 부른다.)
    - 원소들이 서로 관련이 있든 없든간에
    여러 개체를 묶어놓은거면 집합이다.
    - 특정 원소($a$)가 특정 집합($A$)의 원소라는 것은 $a \in A$라고 나타낸다.
    (보통 집합은 대문자로, 원소는 소문자로 쓴다.)
    - 특정 원소가 특정 집합의 원소가 아니라는 것은 $a \notin A$라고 나타낸다.
    - 두 집합이 같은 원소를 가지고 있다면 두 집합은 같다.
    ($\forall x(x \in A \iff x\in B)$일 때 $A$와 $B$는 같다.)
    - 집합의 원소가 없는 집합을 공집합($\emptyset$)이라고 한다.
    - 하나의 원소만을 갖는 집합을 단일 원소 집합이라고 한다.
    
2. 집합을 나타내는 방법
    - 원소 나열법 : 집합의 원소를 하나씩 전부 나열한다.($A = \{1, 2, 3, 4, 5\}$)
    - 조건 제시법 : 집합의 원소의 조건을 나타낸다.($A = \{x | x\text{는 1과 5 사이의 자연수}\}$)
    
3. 부분집합(subset)
    - 한 집합의 원소들이 **모두** 다른 집합의 원소라면 
    한 집합은 다른 집합의 부분집합이라고 할 수 있다.
    ($A \subseteq B$으로 나타낼 수 있다.)
    ($\forall x (x \in A \to x \in B)$라면 $A$는 $B$의 부분집합이다.)
    (부분집합이 아님을 증명하려면 $x \in A$이면서 $x \notin B$인 원소를 찾으면 된다.)
    (두 집합이 같다면 $A \subset B$임과 동시에 $B \subseteq A$이다.)
    - 공집합($\emptyset$)이나 해당 집합 그자체도 해당 집합의 부분 집합이 될 수 있다
    
4. 집합의 크기
    - 집합의 크기란,
    유한 집합에서만 성립하는 개념으로써,
    집합의 원소의 수라고 할 수 있다.
    - 집합 $S$의 크기는 $|S|$의 형태로 표기한다.
    
5. 멱집합(power set)
    - 멱집합이란 특정 집합의 모든 부분집합을 원소로 가지는 집합이다.
    ($S$의 멱집합은 $P(S)$로 표기한다.)
    ($S = \{1, 2, 3\}$이라면
    $P(S) = \{\emptyset, \{1\}, \{2\}, \{3\}, \{1, 2\}, \{2, 3\}, \{1, 3\}, \{1, 2, 3\}\}$)
    - 한 집합의 원소들의 모든 조합을 표현할 때 사용한다.
    - 만약 집합이 $n$개의 원소를 가진다면, 멱집합은 $2^n$개의 원소를 가진다.
    
6. 데카르트 곱
    - ordered(순서가 있는) n-tuple이란,
    원소의 순서가 없는 집합과 다르게 말 그대로 순서가 있는 개체들의 모임이다.
      - ordered n-tuple은 원소와 순서까지 일치할 때 서로 같다고 한다.
    - 원소를 두 개 가지고 있는 ordered 2-tuple을 순서쌍이라고 부른다.
      - 순서쌍은 $(a, b)$와 $(b, a)$를 다른 것으로 판정한다.
    - 데카르트 곱은 집합 두 개의 모든 순서쌍의 집합이다.
    ($A \times B = \{(a, b) |\; a \in A \land b \in B \}$)
    - 예 : $A = \{1, 2\}$ / $B = \{a, b, c\}
    $A \times B = {(1, a), (1, b), (1, c), (2, a), (2, b), (2, c)}$

### 느낀 점 & 배운 점

이번 파트는 말 그대로
집합에 대한 용어를 총정리한 느낌~

- 집합 : 순서에 상관없이 여러 개의 개체를 모은 것
- 공집합 : 말 그대로 원소가 없는 집합
- 부분 집합 : 한 집합의 모든 원소가 다른 집합에 있는 집합
- 멱집합 : 한 집합의 모든 부분 집합들의 집합(공집합, 자기자신 포함)
- 집합의 크기 : 유한 집합에서 집합의 원소의 수
- ordered n-tuple : 순서가 있는 n개의 원소를 지닌 짝
- ordered 2-tuple : 순서가 있는 원소 두 개의 짝($(a, b)$같은 느낌, a와 b는 순서가 있음)

이 정도로 용어는 오케이고,

- A와 B 두 집합이 같다 : $\forall x (x \in A \iff x \in B)$
- A는 B의 부분집합이다 : $\forall x (x \in A \to x \in B)$

이 정도로 같은 집합 / 부분 집합에 대한 엄밀한 정의도 오케이고,

- 원소 나열법 : $A = \{1, 2, 3, 4, 5\}$
- 조건 제시법 : $A = \{x | x는 1에서 5 사이의 자연수\}$

이렇게 집합을 표현하는 방법도 오케이고.

내가 제일 이해하기 어려웠던 데카르트 곱은

> 집합 A와 B가 있을 때 집합 A의 원소와 집합 B의 원소로 만들 수 있는 순서쌍의 집합

이라고 이해하니까 쉬워졌어.

좀 더 일반화하면

> 집합 여러 개가 있을 때 여러 집합의 원소들로 만들 수 있는 ordered n-tuple의 집합

이라고 할 수 있겠네.

$A = \{1, 2\}$
$B = \{a, b, c\}$
$A \times B = \{(1, a), (1, b), (1, c), (2, a), (2, b), (2, c)\}$

$A = {1, 2}$
$B = {a, b}$
$C = {x, z}$
$A \times B \times C = \{ (1, a, x), (1, a, z), (1, b, x), (1, b, z), (2, a, x), (2, a, z), (2, b, x), (2, b, z) \}$

이런 느낌이지.

## 2. 집합의 연산

### 정리

1. 합집합(union)
    - 말 그대로, 집합 두 개를 합한 것.
    - $A \cup B = \{x | x \in A \lor x \in B\}$라고 할 수 있다.
    - $A$와 $B$의 합집합은 $A$ 또는 $B$에 속하거나 양쪽에 모두 속하는 원소들의 집합이다.
    
2. 교집합(intersection)
    - 두 집합 양쪽 모두에 속한 원소들의 집합.
    - $A \cap B = \{x | x \in A \land x \in B\}$라고 할 수 있다.
    - 두 집합의 교집합이 공집합일 때(두 집합에 중복되는 원소가 없을 때)
    두 집합은 서로소(disjoint)라고 한다.
    
3. 포함-배제(inclusion-exclusion) 원리
    - 합집합의 원소의 수를 구하는 방법은
    $|A \cup B| = |A| + |B| - |A \cap B|$이다.
    - 두 집합의 중복되는 원소를 한 번 빼주기만 하면 되기 때문이다.
    
4. 차집합(difference)
    - 한 집합에는 속하지만 다른 집합에는 속하지 않는 원소들의 집합이다.
    - $A - B = \{x | x \in A \land x \notin B\}$
    
5. 여집합(complement)
    - 전체집합($U$)에서 해당 집합의 원소를 뺀 원소들의 집합을 여집합이라고 한다.
    - $\overline{A} = U - A = \{x | x \in U \land x \notin A\}$
    
6. 집합의 항등
    - |내용|이름|
    |---|---|
    | $A \cap U = A$ | 항등 법칙 |
    | $A \cup \emptyset = A$ ||
    |||
    | $A \cup U = U$ | 지배 법칙 |
    | $A \cap \emptyset = \emptyset$ ||
    |||
    | $A \cup A = A$ | 멱등 법칙 |
    | $A \cap A = A$ ||
    |||
    | $\overline{(\overline{A})} = A$ | 보원 법칙 |
    |||
    | $A \cup B = B \cup A$ | 교환 법칙 |
    | $A \cap B = B \cap A$||
    |||
    | $A \cup (B \cup C) = (A \cup B) \cup C$ | 결합 법칙 |
    | $A \cap (B \cap C)= (A \cap B) \cap C$ ||
    |||
    | $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ | 분배 법칙 |
    | $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ ||
    |||
    |||
    | $\overline{A \cap B} = \overline{A} \cup \overline{B}$ | 드 모르간 법칙|
    | $\overline{A \cup B} = \overline{A} \cap \overline{B}$ ||
    |||
    | $A \cup (A \cap B) = A$ | 흡수 법칙 |
    | $A \cap (A \cup B) = A$||
    |||
    | $A \cup \overline{A} = U$| 보수 법칙 |
    | $A \cup \overline{A} = \emptyset$ ||
    - 근데 이거 자연스럽게 추론이 되어서 굳이 빡세게 외울 필요는 없다.
    
7. 중복 집합
    - 같은 원소가 두 번 이상 나타나는 집합이다.
    - 합집합 : 중복되는 횟수가 많은 것을 취함(중복 횟수 합치기 아님)
    - 교집합 : 중복되는 횟수가 적은 것을 취함
    - 차집합 : 중복되는 횟수를 서로 빼면 됨(음수가 나오면 0으로 치환)

8. 컴퓨터에서의 집합의 표현
    - 컴퓨터에서 집합을 표현하는데는 비트열을 사용한다.
    - 각 원소가 있는지 / 없는지 여부를 각 비트를 사용해 표현한다.
    - 두 비트열(집합)의 교집합은 `A & B`, 합집합은 `A | B`로 연산할 수 있다.
    - 여집합은 `U & ~A`, 차집합은 `A & ~B`로 연산할 수 있다.

### 배운 점 & 느낀 점

이번에도 말그대로 집합의 튜토리얼 + 컴퓨터에서 집합이 어떻게 표현되나 느낌임..

정말 쉽게 설명하면,

- 합집합 : 집합 두 개 합친거 - $A \cup B = \{x | x \in A \lor x \in B\}$
- 교집합 : 집합 두 개 겹치는 부분 - $A \cap B = \{x | x \in A \land x \in B\}$
- 차집합 : 집합 한 개에서 나머지 한 개에 없는 것들 - $A - B = \{x | x \in A \land x \notin B\}$
- 여집합 : 집합 한 개에서 해당 집합에 없는 것들 - $\overline{A} = \{x | x \in U \land x \notin A\}$

이렇게 설명할 수 있겠네.

그리고 결국 이런 집합은 다양한 항등식을 가지지.

여기서 기억할만한게 드 모르간 정도?
나머지는 죄다 평범한 추론으로 때울 수 있다고 생각해.

$\overline{A \cap B} = \overline{A} \cup \overline{B}$
$\overline{A \cup B} = \overline{A} \cap \overline{B}$

이게 드 모르간.

그리고 이런 집합의 연산을 하다 보니까
각 연산이 명제 / 비트열에서 어떤 거랑 대응되는지도 알겠더라.

- 합집합 : $A \lor B$ - `A | B`
- 교집합 : $A \land B$ - `A & B`
- 차집합 : $A \land \neg B$ - `A & ~B`
- 여집합 : $\neg A$ - `U & ~A`

이런 식으로 말이야.

근데 명제랑은 뭔가 되게 애매한 느낌?
근데 되게 비슷함.
합집합 / 교집합 / 여집합은 명제의 논리합 / 논리곱 / 논리부정 그대로 이해해도 괜찮은 수준..

그리고 내가 새로 배운 개념은 중복집합 정도?

말 그대로 같은 원소가 여러 개 있을 수 있는 집합으로,

- 합집합 : 각 원소의 최대 갯수
- 교집합 : 각 원소의 최소 갯수
- 차집합 : 각 원소의 갯수를 뺀 갯수(음수가 나오면 0)
- 합(sum) : 각 원소의 갯수를 더한 갯수

이렇게 각 집합 연산이 좀 달라지는거..
