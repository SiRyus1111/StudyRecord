## 1. Nonlocal Jumps - 비지역적 점프

### 정리

1. 유저 레벨의 예외적 제어 흐름, 비지역적 점프
    - C언어는 비지역적 점프(Nonlocal Jump)라고 불리는
    유저 레벨의 예외적 제어 흐름 기능을 제공한다.
    - 이를 이용하면, 일반적인 호출-반환 순서를 거치지 않고
    한 함수에서 현재 실행 중인 다른 함수로 제어 흐름을 넘길 수 있다.
    - 비지역적 점프는 `setjmp` / `longjmp` 함수를 통해 구현된다.
    
2. `setjmp` / `longjmp`
    - `int setjmp(jmp_buf env)`
    - `setjmp` 함수는 나중에 `longjmp` 함수에서 사용할 수 있도록
    현재 호출 환경을 `env` 버퍼에 저장하고 0을 반환한다.
      - 호출 환경이란, PC / 스택 포인터 / 범용 레지스터가 포함된다.
      - `setjmp` 함수의 반환값은 변수에 할당하면 안된다.
      (하지만 `switch` / 조건문에서 조건으로 쓸 수 있다.)
    - `longjmp` 함수는 `env` 버퍼에서 호출 환경을 복원하고,
    가장 최근의 `env`를 초기화한 `setjmp` 호출에서 반환을 트리거한다.
    그러면 `setjmp`는 0이 아닌 반환값 `retval`을 반환한다.
    - 비지역적 점프의 중요한 용도 중 하나는,
    오류 조건이 감지되었을 때 깊게 중첩된 함수 호출에서 즉시 반환할 수 있도록 하는 것이다.
    - 하지만 `longjmp`가 `setjmp`까지의 중간 호출을 건너뛸 수 있기 때문에,
    의도하지 않은 결과를 초래할 수 있다.
      - `longjmp`와 `setjmp` 사이에 오류 발생 시 정리하는 코드가 있다면,
      해당 코드가 실행이 안되어 메모리 누수같은 문제가 발생할 수 있다.
    - 비지역적 점프의 다른 중요한 용도는,
    시그널 수신으로 인해 중단된 명령어로 되돌아가는 대신
    시그널 핸들러에서 특정 코드 위치로 분기하는 것이다.

### 느낀 점 & 배운 점

이번 챕터는 뭔가 되게 신기한데 실제 코드를 짤 때는 거의 안 쓸 것 같은 문법을 배운 것 같아..

비지역적 점프란,
쉽게 말해서
`setjmp()`로 나중에 `longjmp()`를 호출했을 때 되돌려지는 지점을 찍고
`longjmp()`로 마지막으로 `setjmp()`를 했던 지점으로 돌아가는,
순차적 제어 흐름을 거치지 않는 점프라고 할 수 있어.

그러니까 이것도 예외적 제어 흐름인거지.

근데 솔직히 난 이거 쓰기 무서울 듯..
