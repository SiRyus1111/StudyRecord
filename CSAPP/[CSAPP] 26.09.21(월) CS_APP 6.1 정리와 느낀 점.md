## 1. Random-Access Memory - RAM, 임의 접근 메모리

### 정리

1. Static RAM - 정적 메모리(SRAM)
    - SRAM은 각 비트를 쌍안정 메모리 셀에 저장하고,
    이 셀은 6개의 트랜지스터로 구성된 회로로 구현된다.
    - 각 셀은 두 개 중 하나의 상태에서 무한정 유지될 수 있는 특성을 가지고 있다.
      - 다른 상태는 불안정하기 때문에,
      각 셀의 회로는 빠르게 안정된 상태 중 하나로 이동한다.
    - 그리고 결국 한 쪽 상태로 떨어지기 때문에 외부 간섭에 민감하지 않다.
    - 그렇기 때문에, SRAM은 전원이 공급되는 한 무한정 각 메모리 셀이 유지된다.
    - SRAM은 DRAM에 비해 빠르고 비싸다.
      - 그렇기 때문에 캐시 메모리로 주로 사용된다.

2. Dynamic RAM - 동적 메모리(DRAM)
    - DRAM은 각 비트를 커패시터의 전하로 저장하고,
    각 셀은 커패시터와 하나의 액세스 트랜지스터로 구성된다.
    - 저장 밀도를 매우 높일 수 있다.
    - 커패시터는 교란에 매우 민감해서,
    전압에 교란이 발생하면 원래 상태로 복구되지 않는다.
      - 그렇기 때문에 일부 시스템은 오류 정정 코드를 넣어,
      회로가 각 워드 내의 오류 비트를 감지하고 수정할 수 있게 한다.
    - 그리고 커패시터의 전하는 누전되기 때문에,
    보통 10 ~ 100밀리초 안에 전하를 잃게 된다.
      - 그렇기 때문에, DRAM은 주기적으로 리프레시되어야한다.
      - 물론, 컴퓨터는 나노초 단위로 동작하기 때문에 이 유지 시간은 상당히 긴 편이다.
    - DRAM은 SRAM에 비해 느리지만 집적도가 높고 싸다.
      - 그렇기 때문에 메인 메모리로 주로 사용된다.

3. 기존 DRAM의 작동 방식
    - DRAM 내부의 셀(비트)의 집합은 d개의 슈퍼셀로 분할되고,
    각 슈퍼셀은 w개의 DRAM 셀로 구성된다.
      - 즉, $d \times w$ 크기의 DRAM은 총 dw 비트의 정보를 저장할 수 있다.
      - (헷갈릴 수 있는데, 셀 : 각 비트 / 슈퍼셀 : 셀을 묶어서 부르는 단위
      이렇게 이해하면 된다.)
    - 각 슈퍼셀들은 r행 / c열로 이루어진 2차원 배열처럼 구성된다.($rc = d$)
      - 그리고 각각의 슈퍼셀들은 (i, j) 형식의 주소를 가진다.
    - 정보는 핀이라는 외부 커넥터를 통해 칩 안팎으로 전달되고,
    각 핀은 1비트 신호를 전달한다.
    - 각 슈퍼셀에 접근하려면, 먼저 행을 선택(RAS)한 후 그 행을 따로 버퍼에 저장하고
    그 버퍼에서 열을 선택(CAS)하여 각 셀에 접근하게 된다.
    - 슈퍼셀을 2차원 배열로 만드는 이유는, 
    수많은 셀을 제어하는데 필요한 전선 수를 $2 \sqrt{n}$개의 선으로만 제어할 수 있게 되고,
    주소 입력 시 행 주소 / 열 주소를 시간차를 두고 받아 주소 핀 주소를 줄일 수 있기 때문이다.

4. 메모리 모듈
    - 실제로는 한 DRAM 모듈은 여러 개의 DRAM 칩으로 구성되어있다.
    - 그 여러 개의 DRAM 칩을 병렬로 묶어서
    동일한 행 / 열 주소를 동시에 보내
    각 칩에서 같은 위치의 각각의 슈퍼셀(비트들)을 읽어올 수 있다.
    - 이렇게 각 칩이 내놓은 비트들을 합쳐서 
    CPU가 사용하는 큰 데이터 단위를 만들 수도 있다.

5. 향상된 DRAM
    - DRAM에는 다양한 종류가 있고,
    다양한 최적화 방식의 DRAM이 있다.
      - Fast Page Mode DRAM(FPM DRAM) : 같은 행 내의 연속적인 접근이 있을 때,
      RAS 한번으로 버퍼에 저장해놓은 행의 정보를 버리지 않고 접근하는 DRAM
      - Extended Data Out DRAM(EDO DRAM) : 개별 CAS 간의 시간 간격을 더 좁힐 수 있도록 개선된 
      FPM DRAM의 한 형태.
      - Synchronous DRAM(SDRAM) : 클럭 신호와 동기적으로 제어되는 DRAM
      - Double Data-Rate Synchronous DRAM(DDR SDRAM) :
      두 배의 대역폭을 가진 DRAM
      - 등등..

6. 비휘발성 메모리
    - 비휘발성 메모리는 SRAM / DRAM과 다르게 전원이 꺼져도 데이터가 유지된다.
    - ROM은 다양한 유형이 있다.
        - Programmable Rom(PROM) : 정확히 한번만 프로그래밍될 수 있는 ROM
        - Erasable PROM(EPROM) : 빛을 사용해 데이터가 지워지고 재프로그래밍될 수 있는 PROM
        - electrically erasable PROM(EEPROM) : 전기를 사용해 재프로그래밍될 수 있는 PROM
    - 플래시 메모리(흔히 SSD)는 EEPROM을 기반으로 한 비휘발성 메모리의 한 종류이다.

7. 메인 메모리에 접근하기
    - 데이터는 버스라고 하는 통로를 이용해 CPU와 메인 메모리 사이에서 전송된다.
      - 버스 인터페이스에서 I/O 브릿지로는 시스템 버스를 통해서,
      I/O 브릿지에서 메인 메모리로는 메모리 버스를 통해서 전송된다.
    - 그리고 메인 메모리에 대한 접근은 메모리 컨트롤러를 통해 제어된다.
    - 버스를 이용해 주소나 데이터를 주고받는 일련의 과정을 버스 트랜잭션이라고 한다.
      - 읽기 작업 : Read Transection
      - 쓰기 작업 : Write Transection
      - 등등..

## 2. Disk Storage - 디스크 저장장치

### 정리

1. 디스크의 기본 개념
    - 디스크는 데이터를 영구적으로 저장하는 기억장치이다.
    - 디스크에 접근하는데는 메인 메모리에 접근하는 것보다
    압도적으로 시간이 많이 걸린다.
    
2. 디스크의 구조
    - 이건 사진이 필요할 것 같은데 사진 없이 정리해도 괜찮겠지.
    - 어차피 나만 볼건데 뭐..
    - 디스크의 정보가 저장되는 부분은 플래터(Flatter)로 구성되고,
    각 플래터는 자기 기록이 가능한 재료가 코팅된 두 면(Surface)으로 이루어져있다.
    - 플래터 중앙에는 스핀들(Spindle)이 있고, Spindle은 플래터를 일정한 회전 속도로 회전시킨다.
    - 일반적으로 디스크는 여러개의 Flatter로 이루어져있다.
    - Surface는 트랙(Track)이라고 하는 동심원들의 집합으로 구성된다.
    - 각 Track은 여러 섹터(Sector)로 나뉘어져 있고,
    각 Sector에는 해당 Sector에 자기 기록 재료에 인코딩된
    동일한 수의 데이터 비트가 저장된다.
    - 섹터들은 데이터 비트가 저장되지 않는 갭으로 구분된다.
    - 여기까지,
    Flatter -> Surface -> Track -> Sector 순으로 작은 단위이다.
    - 추가적으로, 여러 개의 flatter 표면의 수직으로 같은 위치에 있는 트랙들의 집합을
    실린더(Cylinder)라고 한다.
    
3. 디스크 용량
    - 디스크의 용량은 기록 밀도 / 트랙 밀도에 의해 결정된다.
    - `Sector 당 바이트 * 평균 Track 당 Sector * Surface 당 Track * Platter 당 Surface * Platter의 수`
    
4. 디스크 연산
    - 디스크는 암 끝에 연결된 읽기 / 쓰기 헤드를 사용해서
    Surface에 저장된 비트를 읽고 쓴다.
    - 디스크는 암을 앞뒤로 이동시켜서 헤드를 Surface의 임의의 트랙 위에 이동(Seek)시켜서
    헤드 아래의 비트의 값을 감지(읽기)하거나 비트의 값을 변경(쓰기)할 수 있다.
    - 여러 개의 Flatter를 가진 디스크는 각 Surface마다 별도의 헤드를 가지고 있다.
      - 헤드는 수직으로 정렬되어있으며 같이 움직인다.
    - 디스크의 섹터에 대한 접근 시간에는 다음이 영향을 미친다.
      - 탐색 시간 : 헤드를 대상 섹터가 포함된 트랙 위로 이동시키는 시간
      - 회전 지연 시간 : 헤드가 해당 섹터를 지나갈 때까지 기다리는 시간
      - 전송 시간 : 해당 섹터의 내용을 읽거나 쓰는 시간(회전 속도 / 트랙 당 섹터 수에 따라 달라짐)
    - 공식들도 나와있는데, 중요한 내용은 아니므로 생략.
     
5. 논리 디스크 블록
    - 실제로 디스크의 각 섹터에 접근하는건 복잡하기 때문에,
    디스크 컨트롤러는 B개의 섹터 크기의 논리 블록으로 구성된 단순한 구조를 제공한다.
    - 디스크 컨트롤러는 논리 블록 번호와 물리 디스크 섹터 간의 매핑을 관리한다.
    - 디스크 컨트롤러는 논리 블록 번호를 Surface / Track / Sector로 변환해준다.
    
6. 디스크 연결
    - 디스크는 시스템 버스 / 메모리 버스와 다른
    I/O 버스를 통해 I/O 브릿지에 연결된다.

### 느낀 점 & 배운 점

결국 요약하면 이거야.

1. 디스크는
    - 원판인 Flatter
    - 원판에 정보가 기록되는 부분인 Surface
    - 정보가 기록되는 부분을 동심원으로 나눠놓은 Track
    - 각 Track의 특정 부분인 Sector
    - +@로 여러 겹의 Flatter의 같은 Track을 나타내는 Cylinder
    - 로 단위를 나눌 수 있다.
2. 디스크 연산은 암을 움직여 헤드가 해당 섹터가 있는 트랙을 가리킴으로써 수행되며,
    - 탐색 시간 : 트랙을 찾는데 걸리는 시간
    - 회전 지연 시간 : 트랙에서 섹터를 찾는데 걸리는 시간 
    - 전송 시간 : 정보를 전송하는 시간
    - 으로 디스크의 정보에 접근하는데 걸리는 시간이 나뉜다.
3. 논리적으로는 디스크는 디스크 컨트롤러로 인해 블록으로 나뉘어 접근된다.
4. 디스크같은 I/O 장치는 별도의 I/O 버스를 통해 연결된다.

## 3. Solid State Disks - SSD, 반도체 디스크

### 정리

1. Solid State Disk - SSD
    - SSD는 앞서 6.1.1(비휘발성 메모리)에서 설명했던
    플래시 메모리를 기반으로 하는 디스크이다.
    - 다른 디스크와 마찬가지로 논리적 디스크 블록을 읽고 쓰는 요청을 처리한다.
    - SSD는 하나 이상의 플래시 메모리 칩과 디스크 컨트롤러와 동일한 역할을 수행하는
    플래시 변환 계층(Flash Translation Layer)로 구성된다.
    - 플래시 메모리의 각 블록은 여러 개의 페이지로 구성된다.
      - 데이터는 페이지 단위로 읽히고 쓰인다.
      - 페이지는 해당 페이지가 속한 전체 블록이 지워진 후에만 쓸 수 있고,
      블록이 한 번 지워지면 해당 블록 내의 각 페이지는 추가적인 지우기 작업 없이
      한 번씩 기록할 수 있다.
    - SSD는 읽기 속도가 쓰기 속도보다 빠르다.
      - 이유는, 블록을 지우는데 1ms 정도의 비교적 긴 시간이 소요되기 때문이고,
      쓰기 작업이 기존 데이터가 포함된 페이지를 수정하려고 할 때
      동일한 블록 내의 유효한 데이터가 포함된 모든 페이지를 새로운 블록으로 복사해야하기 때문이다.
    - SSD는 회전식 디스크에 비해 많은 장점이 있다.
      - 움직이는 부품이 없어 Random Access 속도가 훨씬 빠르고,
      전력 소모가 적으며, 내구성이 좋다.
    - 물론 단점도 있는데,
      - 플래시 블록은 반복적인 쓰기 작업으로 인해 마모되기 때문에
      SSD의 각 블록은 마모될 가능성이 있다.
        - 물론 플래시 변환 계층의 마모 균등화 로직으로 전체적인 마모가 분산되기도 한다.
      - 가격이 회전식 디스크보다 비싸다.

### 느낀 점 & 배운 점

이번 챕터는 상당히 짧았어.

그냥

1. SSD는 플래시 메모리를 기반으로 하는 저장장치이다.
2. SSD는 디스크 컨트롤러와 같은 역할을 하는 플래시 변환 계층(FTL)을 둔다.
3. 플래시 메모리의 각 블록은 여러 개의 페이지로 구성된다.
    - 데이터는 페이지 단위로 읽히고 쓰인다.
4. SSD는 블록을 지우는데 시간이 꽤 걸리고, 
기존 데이터가 포함된 페이지를 수정해야할 때 블록 전체를 복사해놔야하기 때문에
쓰기가 읽기 작업보다 더 걸린다.
